## 3. Shorts-일반 영상 캠페인 매핑

**자동 매핑은 일부 가능하지만, 고신뢰 직접 매핑은 아직 낮다. Shorts가 일반 영상으로 체계적으로 이어진다는 증거는 현재 데이터만으로 부족하다. 단정 등급: 관찰됨.**

매핑은 세 단계로 시도했다. 첫째, Shorts description에 일반 영상 URL이 있으면 `direct_teaser`로 분류했다. 둘째, 같은 시리즈명·짝 제목·편명 구조가 있으면 `same_series` 후보로 분류했다. 셋째, 챔피언·라인·게임 모드 키워드가 겹치면 `same_topic` 후보로 분류했다. 나머지는 `channel_level`로 남겼다.

| relationship_type | Shorts 수 | 비중 | 신뢰도 | 해석 |
|---|---:|---:|---|---|
| direct_teaser | 6 | 0.9% | 높음 | description의 풀버전 링크 기반 |
| same_series | 12 | 1.8% | 낮음 | 시리즈 표지어 기반 후보, 수동 검증 필요 |
| same_topic | 363 | 54.0% | 낮음~중간 | 챔피언·라인·모드 공유 후보 |
| channel_level | 291 | 43.3% | 해당 없음 | 개별 일반 영상 매핑 불가 |
| 자동 매핑 후보 합계 | 381 | 56.7% | 혼합 | direct 외에는 캠페인 증거 아님 |

고신뢰 `direct_teaser` 샘플은 최근 이즈리얼/티모 원딜 영상에 집중되어 있다.

| Shorts | 연결 일반 영상 | 근거 |
|---|---|---|
| 달모 절망편ㅣ티모 원딜 | 아아 이것은 '실명'이라는 것이다 | description 풀버전 링크 |
| 달모 희망편ㅣ티모 원딜 | 아아 이것은 '실명'이라는 것이다 | description 풀버전 링크 |
| 이즈리얼 궁 버그? | 이즈리얼 장인에게 야르한 강의 받기ㅣ이론편 | description 풀버전 링크 |
| 개쎈 이즈리얼 스킨 | 이즈리얼 장인에게 야르한 강의 받기ㅣ이론편 | description 풀버전 링크 |
| 이즈리얼 장인의 필살 콤보 | 이즈리얼 장인에게 야르한 강의 받기ㅣ이론편 | description 풀버전 링크 |
| 챌린저 괴롭히는 실버 | 이즈리얼 장인에게 야르한 강의 받기ㅣ이론편 | description 풀버전 링크 |

자동 매핑률 56.7%는 "캠페인 설계가 확인됐다"는 뜻이 아니다. `same_topic`은 같은 챔피언·라인·티어 키워드를 공유하는 후보일 뿐이고, 실제로 Shorts 시청자가 일반 영상을 봤는지는 YouTube Analytics 없이 확인할 수 없다.

## 5. 전환 프록시 추정

**YouTube 총 조회수 대비 Chzzk 팔로워 비율은 0.0407%다. 이는 실제 전환율이 아니라 상한 프록시다. 단정 등급: 추정.**

계산식은 `Chzzk 팔로워 3,760 / YouTube 채널 총 조회수 9,241,534`다. 다른 말로 하면 YouTube 조회수 1,000회당 Chzzk 팔로워 0.41명 수준의 상한이다. 실제 전환율은 이보다 낮을 가능성이 크다. 같은 사람이 여러 번 조회했을 수 있고, Chzzk 팔로워가 YouTube에서 온 사람인지 직접 추적하지 않았으며, 치지직 디스커버리·레이드·외부 클립 유입을 분리하지 않았기 때문이다.
