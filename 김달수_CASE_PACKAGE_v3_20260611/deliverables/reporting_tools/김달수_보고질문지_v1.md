# 김달수 컨설팅 보고 질문지 (v1)

**용도:** 보고가이드(`김달수_보고가이드_v1.md`)와 짝. 보고 진행 중·직후·후속 응대 시점에 본인에게 직접 물을 질문.
**작성:** 2026-06-01
**위상:** 보고가이드의 *체크인 멘트*에서 본인이 답하기 어려울 때 *구조화 선택지*로 보완. 모든 질문은 *묵비권 가능*. 강요 아님.

---

## 사용 원칙

- **질문지 전부 다 쓸 필요 없음.** 현장 판단으로 *일부만 활용*. 가이드 흐름 끊지 말 것.
- **본인이 *침묵·우물거림 반응*일 때** 질문지의 *선택지형* 활용 (자유 답보다 부담 적음).
- **본인이 *반박·우려 반응*일 때** 질문지의 *자유 답형* 활용 (구조화 강요 X).
- **모든 질문은 *위계 없음*** — 답하기 편한 것만 답해도 OK.
- **본인 답을 *그대로 인용*** 권고. 표준어로 옮기지 말기 (방법론 v1 §1.5 어휘 처리 원칙).

# Part A — 보고 진행 중 (가이드 체크인 보강)

가이드의 4개 체크인 지점에서 본인이 *침묵·모호*할 때 활용.

## A1. 도입부 후 — 채널 정체성 정렬 확인

**가이드 체크인:** "이해 안 되는 거 있으면 바로 말씀해 주세요."

**보강 질문 (필요 시):**

> "리포트에서 달수님 채널을 *'롤로 사람 데려와서, 사람으로 정붙는' 사촌동생 같은 채널*이라고 정의했는데, 본인이 보시기에 어느 쪽이세요?"
>
> A. 거의 맞아요
> B. 어느 정도 맞는데 일부 다른 부분 있어요
> C. 좀 다르게 느껴요
> D. 잘 모르겠어요

**결과 해석:**
- A → 그대로 진행
- B → "*어느 부분*이 다르게 느껴지세요?" 자유 답 받기
- C → **중요 신호.** 정체성 추출이 본인 인식과 어긋날 가능성. 가이드 1막 진입 전 정체성 재합의 권고
- D → 무리하게 답 끌어내지 말기. 그대로 진행하며 본인 반응 주시

## A2. 1막 후 — 본인 인식 정렬 (긍정 발견)

**가이드 체크인:** "여기까지 어떠세요? 본인이 느끼던 거랑 비슷한가요, 아니면 다른가요?"

**보강 질문 (필요 시):**

> "상위 8%라는 결과가 본인이 평소 느끼던 자기 위치랑 어느 정도 맞나요?"
>
> A. 생각보다 높게 나와서 놀랐어요
> B. 어느 정도 짐작은 했는데 데이터로 보니 확실해졌어요
> C. 비슷한 느낌이었어요
> D. 솔직히 잘 와닿지 않아요

**결과 해석:**
- A → *과소 자기 평가형*. 데이터 신뢰가 본인 자기 평가 정정에 작동. 가이드 진행 계속.
- B → *적정 자기 평가형*. 데이터가 *확인 자료*로 작동. 무난.
- C → *기존 인식 정렬*. 데이터의 *추가 가치* 부족 가능. 다음 영역에서 *어떤 가치 제공*인지 강조 필요.
- D → **본인 자기 의심 신호 가능성.** 무리하게 설득하지 말고 *시간 주기*. 2막 데이터로 보강.

## A3. 2막 후 — 데이터 신뢰 (1년 추이)

**가이드 체크인:** "1년 데이터까지 봤어요. 이제 좀 다른 얘기를 드릴 건데, 마음 단단히 잡으셔도 돼요. 나쁜 얘기는 아니에요."

**보강 질문 (필요 시):**

> "1년간 3배 넘게 성장했다는 결과 보면, 본인이 *그 성장을 체감*하셨는지 궁금해요."
>
> A. 네, 체감했어요
> B. 일부 체감했는데 데이터처럼 크다고는 안 느꼈어요
> C. 체감 못 했어요 — 데이터가 더 큰 그림이에요
> D. 잘 모르겠어요

**결과 해석:**
- A → 데이터-체감 일치. 강함.
- B → *부분 자기 평가 격차*. 데이터가 본인 인식 보강.
- C → **중요 발견.** 본인이 *자기 발전을 못 본 상태*. 이게 *왜 컨설팅 가치 있는지* 본인에게 직접 작용. 강조 권고.
- D → 무리하게 답 끌지 말기.

## A4. 3막 후 — 흔들림 캐치 (한계·트레이드오프)

**가이드 체크인:** "여기까지 들으시면서 어떤 느낌이세요? 혹시 *납득 안 되는 부분* 있으면 지금 같이 짚어볼게요."

**보강 질문 (필요 시):**

> "3막 내용 중에 가장 *마음에 걸리는 부분*이 있으시다면?"
>
> A. 1만 가서 진성도 1%로 떨어지는 거
> B. 노방종 효과 없다는 거
> C. 챌린지 숏폼 효과 없다는 거
> D. 참여 밀도 떨어지고 있다는 거
> E. 다 OK, 마음에 걸리는 거 없어요

**결과 해석:**
- A → 가이드 3막 예상 질문 1번 활용 ("1만 가지 말라는 거 아님")
- B → 예상 질문 2번 활용 ("평소 방송 줄이라는 거 아님")
- C → 예상 질문 (숏폼 인과 미추적) 활용
- D → **자기 의심 강화 위험.** 3막의 *예방 가이드* 톤 다시 강조. "*잘못된 게 아니라 *주의해야 할* 영역*"
- E → 안전. 클로징 진행.

**중요:** 본인이 *둘 이상 선택*하면 *가장 무거운 것부터 짚기*. 한꺼번에 다 답하려 하지 말 것.

# Part B — 보고 직후 (액션 확약 보강)

가이드 클로징의 액션 확약을 강화. 본인이 *1개 선택 후* 추가 합의.

## B1. 액션 1개 선택 확인

**가이드 멘트:** "오늘 들은 거 중에서 *내일 방송에서 한 가지만* 시도해보신다면 뭘 고르시겠어요?"

**선택지 (가이드와 동일):**

1. 방송 끝나고 통계 볼 때 *최고 시청자 + 채팅*만 보기 (평청 무시)
2. 단골 시청자 한 명 호명·인사
3. 다음 노방종 *안 하고* 그 에너지 정상 방송에 쓰기
4. 다음 숏폼 1개 *롤 영상*으로 올리기

**본인 선택 기록:** ____

**진입장벽 점검:**
> "선택하신 거, 다음 방송에서 *실제로* 할 수 있을 것 같으세요? 아니면 *부담스럽다·어렵다* 부분 있으세요?"

부담 신호 발견 시 → *1번(지표 전환)*으로 하향 권고. 행동 변화 0이라 거절 명분 없음.

## B2. 실행 시점 합의

> "다음 방송 언제예요? 그 방송에서 한 번 해보시는 걸로 합의할까요?"

**합의 기록:** 다음 방송일 ____ / 실행 약속 (예/아니오) ____

## B3. 트래킹 방법 합의

선택한 액션에 따라:

- **1번 (지표 전환):** "방송 끝나고 *최고 시청자·채팅 숫자만* 메모해두실래요? 트래킹 시트 안 만들어도 되고, 메모장이나 디스코드에 본인만 보이는 채널에 적어두는 정도면 충분해요."
- **2번 (단골 호명):** "*몇 명 호명했는지* 방송 후 짧게 기록하는 정도. 강박 X."
- **3번 (노방종 안 함):** "이번 주 노방종 *안 함* 자체가 트래킹. 추가 기록 불필요."
- **4번 (롤 숏폼):** "*업로드 사실*만 알려주세요. 조회수·반응 자동 추적 안 함."

**핵심:** *부담 최소.* 방법론 v1 §11.1 "한 방송당 입력 3~5분 이내" 원칙. 이게 안 되면 *지속 안 됨*.

## B4. 다음 응대 시점 합의

> "이거 시도해보시고 *어땠는지* 다음에 짧게 얘기 나눌까요? 1주일 후? 2주일 후?"

**합의 기록:** ____ (1주 / 2주 / 1달 / 미정)

본인이 *"미정·생각해볼게요"* 답이면 → 무리하게 합의 끌지 말기. *"필요할 때 편하게 말씀해주세요"*로 마무리.

# Part C — 후속 응대 영역 (방법론 v1 §11·§12)

보고 직후 *아닌* 시점. 1주~3개월 후 응대 시 활용. 한꺼번에 다 묻지 말고 *그때그때 1~2개*.

## C1. 자기 평가 메커니즘 변화 (1번 액션 선택 시·1개월 후)

> "지난번에 *peak·채팅 위주로 보기* 시작하셨는데, 어떠셨어요?"
>
> A. 마음이 편해졌어요 (자기 의심 줄어듦)
> B. 별 차이 없어요
> C. 오히려 더 신경 쓰여요
> D. 자꾸 다시 평청 보게 돼요

**결과 해석:**
- A → 작동. 강화 권고.
- B → 인식 변화 미발생. 다른 액션 검토.
- C → *과집착 신호*. 트래킹 자체가 부담일 수 있음. 잠시 *트래킹 중단*도 옵션.
- D → 습관 미정착. *왜 다시 평청 보는지* 자유 답으로 확인.

## C2. 응대 핵심 영역 변화 (3개월 후 또는 신호 발견 시)

> "최근 방송하시면서 *불안하거나 의심되는 영역*이 있으세요?"
>
> 자유 답.

**해석 가이드:**
- *자기 의심·자기 검열 신호*가 새로 발현되면 — 케이스 2 (구비바) 통합 진단 패턴이 김달수에게도 작동하는지 점검. 단 *단정 금지*. 본인 발화 그대로 받기.
- *외부 환경 신호*(플랫폼·MCN·시청자 변화) 발현 시 — 재진단 트리거(방법론 v1 §12.3) 발동 검토.

## C3. 외부 환경 변화 (NOB 진입 등)

**기록:** NOB 미팅 결과 / 새 제안 / 본인 결정 ____

## C4. 선행지표 검증 시점 (3~6개월 후)

> "리포트 받으신 지 (3개월/6개월) 정도 됐네요. *그때 받은 분석이 실제 방송에서 맞았는지* 같이 짚어볼까요?"

**검증 항목 (방법론 v1 §12.2):**

## 한계·짚어둘 점

**1. Part C2(자기 의심 영역)가 김달수에게도 작동하는지 미검증.**
케이스 2(구비바) 학습에서 *자기 가치 평가 낮춤 통합 진단* 발견됐으나, 케이스 1(김달수)에서는 *자기 의심 약*으로 박혀 있음 (부록 E). **김달수에게 무리하게 적용 금지.** 본인 발화 패턴 발견 시에만 점검.

**2. 본인 합의 영역 점검 필수.**
김달수 케이스는 *친분 관계로 평서체 합의*. 정식 합의서 발송 안 됨. *재정·신원·관계* 영역 자발 노출만 분석에 반영. Part C2·C3에서 *본인이 자발 말하지 않은 영역*은 캐지 말기.

**3. 질문지 자체의 부담.**
질문지 형식이 *본인에게 인터뷰 강박*을 줄 수 있음. *대화 흐름에 자연스럽게 녹이기* 권고. 4~5개 한꺼번에 묻기 금지.
