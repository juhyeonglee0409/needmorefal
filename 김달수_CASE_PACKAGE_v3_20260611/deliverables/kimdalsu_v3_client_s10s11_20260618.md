# 채널 진단 보고서 — §10~§11: 실행설계와 트래킹

**분석 대상:** 치지직 채널 (팔로워 3,760명, 리그 오브 레전드 주력)  
**분석 기준일:** 2026년 6월 18일  
**데이터 범위:** §5~§8 전체 진단 결과  
**버전:** v3 §10~§11 (진단→실행 전환)

---

> **결론 카드 ①**  
> §5~§8이 진단이었다면, §10~§11은 처방전이다. 핵심 원칙은 두 가지이다. 첫째, **가장 쉬운 것부터 시작한다** — 전환 파이프라인(P2)은 description 템플릿 하나로 착수할 수 있고, 효과 측정도 가능하다. 둘째, **가장 어려운 것은 단계적으로 접근한다** — 방송시간 축소(P1)는 세션 분할로 시작해서 총량 조정으로 이행한다. 모든 실행 항목은 "동사 + 시간 + 횟수 + 대상" 수준으로 정의하되, 스트리머 본인과의 협의 후 확정해야 한다.

# §10 실행설계

## §10.1 실행 순서 — 왜 이 순서인가

**§8의 장벽 난이도 분석에서 도출한 순서이다. 난이도가 낮고 측정 가능한 것을 먼저 실행해서 작은 성공을 만들고, 그 성공이 다음 단계의 동기가 되는 구조이다.**

| 단계 | 실행 항목 | 대응 우선순위 | 대응 장벽 | 난이도 |
|---|---|---|---|---|
| 1단계 | 유튜브 전환 퍼널 설계 | P2 | §8.4 (파이프라인 공백) | 낮음 |
| 2단계 | 방송 세션 분할 | P1 전반부 | §8.1 (노방종 관성) | 중간 |
| 3단계 | 방송 총시간 축소 | P1 후반부 | §8.1 (노방종 관성) | 높음 |
| 4단계 | 인접 콘텐츠 실험 | P3 | §8.3 (단일 소재) | 중간 |

P4(팔로워 풀 확대)는 독립 실행 항목이 아니다. 1~4단계 실행의 결과로 따라오는 지표이다.

1단계와 2단계는 병행할 수 있다. 3단계는 2단계의 잔류율 변화를 확인한 후 시작한다. 4단계는 1~2단계와 독립적이므로 여력이 있을 때 시작할 수 있지만, P1/P2보다 우선하지 않는다.

## §10.2 1단계: 유튜브 전환 퍼널 설계

**현재 672개 Shorts 중 6개(0.9%)에만 다음 행동으로 이어지는 링크가 있다. 이것을 100%로 올리는 것이 1단계의 전부이다.**

### 실행 항목

| 항목 | 동사 | 대상 | 시간/횟수 | 비고 |
|---|---|---|---|---|
| A | 작성한다 | Shorts description 표준 템플릿 | 1회 | 치지직 라이브 링크 + 풀버전 연결(해당 시) 포함 |
| B | 적용한다 | 신규 업로드 모든 Shorts | 매 업로드 | 템플릿 복사-붙여넣기 |
| C | 기록한다 | 일별 치지직 팔로워 수 | 매일 1회 | KST 03:00~05:00 권장 (§7 업그레이드 경로) |
| D | 비교한다 | Shorts 업로드일 전후 팔로워 변화 | 주 1회 | C의 데이터로 산출 |

### 템플릿 예시

```
🔴 치지직 라이브: https://chzzk.naver.com/[채널URL]
📺 풀버전: [해당 일반 영상 URL] (해당 시에만)
```

### 착수 조건

없음. 즉시 실행 가능하다.

### 성공 기준

| 지표 | 현재 | 4주 후 목표 | 측정 방법 |
|---|---|---|---|
| 신규 Shorts 링크 적용률 | 0.9% | 100% | 업로드 건별 확인 |
| 일별 팔로워 스냅샷 | 미수집 | 28일 연속 기록 | 수동 또는 자동 스냅샷 |

> 4주 후 팔로워 변화량이 유의미하게 나타나지 않더라도 실패가 아니다. 전환 프록시 0.0407%에서 측정 가능한 변화가 나오려면 충분한 Shorts 조회수가 필요하며, 4주는 기준선 확보 기간이다.

## §10.3 2단계: 방송 세션 분할

**총 방송시간을 유지한 채 세션 길이를 줄이고 방송 일수를 늘린다. "줄이는" 것이 아니라 "나누는" 것이 이 단계의 프레이밍이다.**

### 현재 패턴 (추정)

정확한 세션별 데이터는 미보유이지만, 월 162.7시간을 30일로 단순 분배하면 일 평균 5.4시간이다. 노방종 패턴이라면 특정 일에 10시간 이상 방송하고 쉬는 날이 있는 비균등 분배일 가능성이 높다.

> 단정 등급: **추정** — 세션별 방송 기록이 없어 패턴을 확인할 수 없다. 스트리머 본인 확인 필요.

### 실행 항목

| 항목 | 동사 | 대상 | 시간/횟수 | 비고 |
|---|---|---|---|---|
| A | 설정한다 | 세션 종료 시각 | 매 방송 | 시작 후 4~5시간에 종료 알림 |
| B | 늘린다 | 주간 방송 일수 | 주 5일 이상 | 총 시간 유지 목적 |
| C | 기록한다 | 세션별 시작·종료·평균·피크 | 매 방송 | 잔류율 변화 추적용 |

### 착수 조건

1단계(전환 퍼널)와 동시 착수 가능. 단, 스트리머 본인과 세션 길이·일수에 대한 협의가 선행되어야 한다.

### 성공 기준

| 지표 | 현재 | 8주 후 목표 | 근거 |
|---|---|---|---|
| 세션 평균 길이 | ~5.4h (추정) | 3~4h | 세션 분할 |
| 주간 방송 일수 | 미확인 | 5~6일 | 총 시간 유지 |
| 잔류율 | 0.418 | 0.45~0.50 | 코호트 80-150h 밴드 중앙 0.299 대비 보수 설정 |
| 뷰어십 | 11,253 | 11,000 이상 유지 | 총 시간 유지 전제 |

> 잔류율 목표 0.45~0.50은 코호트 밴드 중앙값(80-150h: 0.299)이 아니라, 현재 0.418에서의 **개선폭**으로 설정했다. 세션 분할만으로 잔류율이 밴드 중앙까지 올라갈 것이라는 보장은 없다.

## §10.4 3단계: 방송 총시간 축소

**2단계에서 세션 분할의 잔류율 효과를 확인한 후, 총 방송시간을 162.7시간에서 80~100시간으로 줄인다.**

### 착수 조건

2단계 실행 8주 후, 다음 두 조건을 **모두** 충족할 때 시작한다.

| 조건 | 기준 | 근거 |
|---|---|---|
| 잔류율 개선 확인 | 잔류율 ≥ 0.45 (4주 평균) | 세션 분할 효과가 실제로 존재함을 확인 |
| 뷰어십 유지 확인 | 뷰어십 ≥ 10,000 (4주 평균) | 세션 분할이 총량을 깎지 않았음을 확인 |

조건 미충족 시 2단계를 유지하거나 세션 길이를 추가 조정한다. 총시간 축소로 강행하지 않는다.

### 실행 항목

| 항목 | 동사 | 대상 | 시간/횟수 | 비고 |
|---|---|---|---|---|
| A | 줄인다 | 월간 총 방송시간 | 162h → 120h (1차) | 4주 유지 후 평가 |
| B | 줄인다 | 월간 총 방송시간 | 120h → 80~100h (2차) | 1차 결과 확인 후 |
| C | 모니터링한다 | 잔류율·뷰어십·평균 시청자 | 주 1회 | 경보 하한(§6.4) 체크 |

### 성공 기준

| 지표 | 2단계 종료 시 | 3단계 완료 시 목표 | 근거 |
|---|---|---|---|
| 방송시간 | ~162h | 80~100h | 코호트 중앙값(71.2h) 근방 |
| 잔류율 | 0.45~0.50 | 0.55~0.65 | 동급생 중앙(0.645) 접근 |
| 평균 시청자 | ~69 | 90~120 | MS1(120) 진입 경로 |
| 뷰어십 | ~11,000 | 9,000~12,000 | §6.3 MS1 시뮬레이션 범위 |

> 단정 등급: **추정** — 방송시간 축소 → 잔류율 개선 → 평균 시청자 상승은 코호트 밴드 분포 기반 시나리오이다. 본 채널에서 동일 효과가 재현되는지는 3단계 실행 결과로만 확인할 수 있다.

## §10.5 4단계: 인접 콘텐츠 실험

**LoL 100% 의존에서 벗어나기 위한 소규모 실험이다. LoL을 떠나는 것이 아니라, LoL 생태계 인접 게임(TFT, 발로란트 등)으로 확장한다.**

### 실행 항목

| 항목 | 동사 | 대상 | 시간/횟수 | 비고 |
|---|---|---|---|---|
| A | 배정한다 | 주 1회 비LoL 세션 | 주 1회, 2~3시간 | 총 방송시간의 10~15% |
| B | 기록한다 | 비LoL 세션 잔류율·평균·피크 | 매 세션 | LoL 세션과 비교 |
| C | 비교한다 | LoL 세션 vs 비LoL 세션 잔류율 | 4주 후 | 최소 4세션 데이터 |

### 착수 조건

1~2단계와 독립적. 여력이 있을 때 시작. 단, P1/P2 실행에 방해가 되지 않는 범위 내에서.

### 참고 데이터

TFT2 카테고리 잔류율 0.725(§4.5)는 같은 스트리머의 비LoL 세션에서 잔류율이 올라간 사례이다. 표본 1건이므로 일반화할 수 없지만, "비LoL = 시청자 이탈"이라는 가정이 반드시 맞지는 않는다는 단서이다.

### 성공 기준

| 지표 | 기준 | 해석 |
|---|---|---|
| 비LoL 세션 잔류율 ≥ 0.40 | LoL 세션(0.418)과 동등 | 다각화 실행 가능 |
| 비LoL 세션 잔류율 < 0.30 | LoL 대비 유의미한 하락 | 해당 게임 중단, 다른 게임 시도 또는 다각화 보류 |

# §11 트래킹 체계

## §11.1 측정 구조

**모든 실행 항목의 효과를 확인하려면 최소한 일별 스냅샷이 필요하다. 치지직은 일별 CSV(287일)가 확보되어 교차 시계열 분석이 가능해졌으나, 유튜브는 여전히 누적 조회수 단일 스냅샷이라 일별 증분 기반 "전후 비교"가 불가능하다.**

### 일별 수집 항목

| 플랫폼 | 지표 | 수집 시각 | 수집 방법 |
|---|---|---|---|
| 치지직 | 팔로워 수 | KST 03:00~05:00 | Softcon 또는 수동 |
| 치지직 | 전일 방송 세션 수·시간·평균·피크 | KST 03:00~05:00 | Softcon 또는 수동 |
| 유튜브 | 영상별 조회수 (신규 업로드만) | KST 03:00~05:00 | YouTube Data API v3 |
| 유튜브 | 채널 구독자 수 | KST 03:00~05:00 | YouTube Data API v3 |

> KST 03:00~05:00은 방송 종료 후·다음 방송 시작 전 사이의 조용한 시간대이다(§7 업그레이드 경로 권장).

### 주간 리뷰 항목

| 지표 | 산출 방법 | 사용처 |
|---|---|---|

### 월간 마일스톤 체크

| 지표 | 경보 조건 (§6.4) | 조치 |
|---|---|---|

| 잔류율 | < 0.30 | 방송시간 추가 축소 또는 편성 재검토 |
| 전환율 (avg/팔로워) | < 1.0% | 팔로워 비활성화 점검 |
| 유튜브 업로드 | < 3건, 2개월 연속 | P2 파이프라인 점검 |

## §11.2 전환 프록시 추적

**§7에서 산출한 전환 프록시(0.0407%)의 변화를 추적하는 것이 1단계 효과 측정의 핵심이다.**

일별 팔로워 스냅샷이 확보되면, Shorts 업로드일 기준으로 다음을 산출할 수 있다.

| 지표 | 산출식 | 의미 |
|---|---|---|
| 업로드 후 팔로워 변화 | 업로드 익일 팔로워 - 업로드 전일 팔로워 | 단건 Shorts의 단기 전환 효과 |
| 주간 팔로워 순증 / 주간 Shorts 조회수 | (주말 fol - 주초 fol) / 주간 Shorts 조회수 합 | 전환 프록시의 주간 근사치 |

현재 프록시(0.0407%)가 1단계 실행 후 0.05% 이상으로 올라가면, description 링크의 전환 기여가 있다고 판단할 수 있다. 0.1% 이상이면 유의미한 개선이다.

> 단정 등급: **추정** — 전환 프록시 자체가 상한 추정치이므로, 변화량도 상한 수준의 변화를 보는 것이다. 실제 전환 인과는 이 방법으로 확인할 수 없다.

## §11.3 단계별 타임라인

**아래 타임라인은 권장 일정이며, 스트리머 본인과의 협의 후 확정한다.**

| 주차 | 1단계 (전환 퍼널) | 2단계 (세션 분할) | 3단계 (총시간 축소) | 4단계 (인접 콘텐츠) |
|---|---|---|---|---|
| W1~W2 | 템플릿 작성·적용 시작 | 세션 길이 목표 협의 | — | — |
| W3~W4 | 신규 업로드 100% 적용 | 세션 분할 시작 | — | (여력 시 시작 가능) |
| W5~W8 | 팔로워 기준선 확보 | 세션 분할 지속 | — | 주 1회 비LoL 실험 |

> 이 타임라인은 "모든 것이 계획대로 진행될 때"의 최선 시나리오이다. 2단계에서 잔류율이 오르지 않으면 3단계 착수가 늦어지고, 업로드 빈도가 회복되지 않으면 1단계의 효과 측정이 지연된다.

## §11.4 리포트 주기와 체크포인트

| 시점 | 리포트 | 판단 사항 |

| W4 | 1차 체크포인트 | 1단계 적용률 100% 달성 여부. 팔로워 기준선 수집 정상 여부 |
| W8 | 2차 체크포인트 | 2단계 잔류율 변화 방향. 전환 프록시 기준선 |
| W12 | 중간 리뷰 | 3단계 착수 조건 판단. 4단계 실험 결과 1차 평가 |
| W24 | 종합 리뷰 | MS1 진입 경로 평가. 전체 전략 재검토 |

W12 중간 리뷰에서 3단계 착수 조건(잔류율 ≥ 0.45, 뷰어십 ≥ 10,000)이 충족되지 않으면, 다음 중 하나를 선택한다.

| 상황 | 대응 |
|---|---|

| 뷰어십 하락 (< 9,000) | 세션 분할이 총량을 깎고 있음. 방송 일수 증가로 보전 시도 |
| 둘 다 악화 | 2단계 롤백. 원래 패턴 복원 후 원인 재분석 |

## 한계

1. 모든 타임라인과 목표 수치는 코호트 밴드 분포 기반 추정이며, 본 채널에서의 실제 효과는 실행 결과로만 확인 가능
2. 세션별 방송 기록(시작·종료·세션 길이)이 현재 미보유. 2단계 착수 전 현재 패턴 파악이 선행되어야 함
3. 일별 스냅샷 수집은 수동 또는 별도 자동화 구축이 필요하며, 수집 자체가 실행 부담이 될 수 있음
4. 전환 프록시 변화는 인과가 아닌 상관 수준의 관찰임. "링크를 넣었더니 팔로워가 늘었다"가 반드시 "링크 때문에 늘었다"를 의미하지 않음
5. 스트리머 본인의 의향·사정이 반영되지 않은 상태. 모든 실행 항목은 협의 후 확정 필요
6. 4단계(인접 콘텐츠) 성공 기준의 잔류율 0.40은 현재 LoL 잔류율(0.418) 기준이며, 게임별 특성에 따라 조정 필요

---

> **결론 카드 ②**  
> 실행 설계의 핵심은 순서와 조건이다. 1단계(전환 퍼널)는 조건 없이 즉시 시작한다. 2단계(세션 분할)는 1단계와 병행한다. 3단계(총시간 축소)는 2단계의 결과를 확인한 후에만 시작한다. **"잘 되면 다음 단계, 안 되면 멈추고 재검토"가 이 설계의 안전장치이다.** W24 종합 리뷰 시점에 MS1(avg 120) 진입 경로가 보이지 않으면, §5의 우선순위와 §6의 마일스톤 자체를 재검토한다.
