# 크몽 페이지 반영 체크리스트 (2026-07-09, operator 직접 수정용)

검수 발견 5건 + 가격 워딩 개편. 위에서 아래로 크몽 편집 화면 순서대로 배치.

---

## A. 가격 워딩 개편 (확정: 정식 전환 예정가 150k/300k/600k)

- [ ] **패키지 구성 섹션 상단**의 파일럿 문구를 아래로 교체:

> ※ 현재 파일럿 운영 기간 가격입니다. 파일럿 종료 시 정식 가격으로 전환됩니다 —
> **정식 전환 예정가: STANDARD 150,000 / DELUXE 300,000 / PREMIUM 600,000**
> 초기 참여자에 한해 상위 구성 업그레이드 혜택이 있습니다. 자세한 내용은 상담 시 안내드립니다.

- [ ] 각 패키지 제목 라인에 예정가 병기 (권장 형식):
  - `STANDARD — 채널 건강검진 보고서 (파일럿 79,000 · 정식 전환 예정가 150,000)`
  - `DELUXE — 성장진단 전략 보고서 (파일럿 139,000 · 정식 전환 예정가 300,000)`
  - `PREMIUM — 1년치 성장전략 설계 및 실행 코칭 (파일럿 290,000 · 정식 전환 예정가 600,000)`
- [ ] ❌ 금지 확인: "정가"라는 단어 + 취소선 조합이 페이지 어디에도 없을 것 (취소선을 쓰려면 반드시 "정식 전환 예정가" 라벨과 함께)

## B. 검수 발견 수정 5건

- [ ] **B1 (🔴 자기소개)**: "치지직 스트리머 전수에 가까운 20,000여 개 채널의 1년치 데이터" → **"치지직 버튜버 전수 7,400여 개 채널의 1년치 데이터"** (실보유와 일치, 본문과 통일. 치지직 전체 표기는 실제 수집 후에)
- [ ] **B2 (🔴 수정 횟수 통일)**: 3곳을 **1 / 2 / 4회**로 통일
  - 가격표 "주요 특징" 문단 (현재 3/6/9)
  - 가격표 하단 수정 횟수 필드 (현재 1/1/4 — DELUXE만 2로)
  - "수정 및 재진행" 규정 (현재 1/2/4 — 기준, 유지)
- [ ] **B3 (🟡 "100여 개" 잔존)**: 무료 사전 확인 제외 항목 "동급 채널 100여 개 분석" → "동급 채널 전수 비교 분석"
- [ ] **B4 (🟡 상품명/타이틀)**: 페이지 타이틀이 아직 "치지직 동급 100개 채널 비교…" — 상품명 필드 재저장 확인 (캐시면 시간 두고 재확인)
- [ ] **B5 (🟡 STANDARD 리뷰 방식)**: 서비스 설명 "결과 리뷰 채팅" ↔ 가격표 "강의·컨설팅 1회 120분" 불일치 — 한쪽으로 통일 (권장: 설명 쪽을 "결과 리뷰 세션 1회(120분)"로 상향 표기)
