# 파일럿-2: 소프트콘 버추얼 랭킹 경로 검증 (2026-07-04)

- 수집 경로: Chrome MCP + operator 인증 세션 (checkpoint operator 통과). nodriver 무인 루트는 미부트스트랩 프로필로 실패 → 사용자 세션으로 대체.
- 대상: `viewership.softc.one/ranking/virtualsoftcone` (버추얼 소프트콘 랭킹)

## 확인된 사실

1. **소프트콘에 버추얼 전용 랭킹이 존재** — 스트리머 랭킹 하위 "버추얼 랭킹" 메뉴. 총 400채널(4페이지, 4페이지는 멤버십 잠금). 태그 필터에 **소속사명 직접 노출**: 버츄얼/이세계아이돌/스텔라이브/에스더/아카이브/허니즈 → S3 소속사 블랙리스트 시드로 재사용 가능.
2. **소형 버튜버도 개별 추적됨** — 꽃분홍(팔로워 1,170)도 완전한 시계열(동시최고 89, 평균46, 방송31.7h, 최고순위, 잔디)을 가짐. **플랜 B(치지직 폴링으로 지표 자체 축적) 불필요** — 소프트콘이 소형까지 커버.
3. 페이지당 지표: 순위/포인트/방송시간/최고시청자/평균시청자/뷰어십. cid는 행 링크에서 복원 가능. 1~3페이지에서 chzzk 채널 169개 추출.

## 결정적 발견: 두 소스가 다른 세그먼트를 잡는다

소프트콘 상위 300위 버추얼 랭킹의 **평균시청자 100~600 구간 28명을 chzzk API로 조인**한 결과:

- 이메일 공개율 **39% (11/28)** — 매우 높음
- 그러나 **팔로워 분포 min 10,655 / median 42,166 / max 129,720** — 전원 밴드(150~10k) **초과**
- 공개 이메일 다수가 소속사 도메인: pixelnetwork.co.kr, sandboxnetwork.net, enchantenter.co.kr, gysent.com, listella.tv → **개인세 아님, S3에서 걸러야 할 대상**

즉 소프트콘 "평균시청자"는 팔로워와 스케일이 다르다. 평균시청자 100~600인 버추얼 채널도 실제 팔로워는 1만~13만인 **기성 대형/소속사 버튜버**다.

**결론**: 소스별 역할이 데이터로 확정됨.

| 소스 | 잡는 세그먼트 | 용도 |
|---|---|---|
| chzzk 라이브검색 API 폴링 | 개인세 소형/신인 (팔로워 수백~수천, 꽃분홍·첼로·알레아) | **발견 (S1) — 우리 타겟** |
| 소프트콘 버추얼 랭킹 top 300 | 기성 대형·소속사 (팔로워 1만+) | 타겟 아님. 단 발견된 cid의 **지표 보강(S6)** 소스로는 소형까지 유효 |

## 스펙 반영

- S1 발견 주력 = **치지직 라이브검색 폴링 누적** (소프트콘 상위 랭킹은 타겟 밴드를 못 덮음).
- S6 지표 보강 = 소프트콘 채널 상세 페이지 (소형까지 커버 확인). Chrome MCP(사용자 세션) 또는 부트스트랩된 nodriver 프로필.
- S3 소속사 블랙리스트에 소프트콘 태그 필터의 소속사명 + 조인에서 발견된 도메인(pixelnetwork/sandboxnetwork/enchantenter/gysent/listella) 추가.
- 소프트콘 하위 랭킹(300~400위, 멤버십 잠금)에 밴드 채널이 더 있을 수 있으나 잠금 — 확인 보류.
