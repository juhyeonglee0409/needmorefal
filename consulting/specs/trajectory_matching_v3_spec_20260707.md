## 3. 정의 (재현 가능 수준)

### 3.1 레벨 통과 시점 t0
채널의 **3개월 이동중앙값**이 기준 레벨 L(구비바 현재 3개월 중앙값 = 16.7명)의 ±10% 밴드에 **처음 진입한 월**. 이동중앙값을 쓰는 이유: 정수 반올림·단발 스파이크로 인한 가짜 통과 방지.

### 3.2 시장 조정 기울기 α
```
α_ch(w) = slope_ch(w) − median{ slope_j(w) : j ∈ 같은 체급 밴드(±50%) 코호트, 같은 캘린더 윈도우 w }
```
같은 달력 기간의 동급 중앙 기울기를 빼서 플랫폼 성장분(베타)을 제거. 모든 성장 판정은 slope가 아니라 **α 기준**.

### 3.3 궤적 유사도 (Track A용)
1. 정규화: 궤적을 창 시작 시점 값으로 나눔 (레벨 차 제거)
2. 거리: 정규화 궤적 간 **RMSE** (단일 기준 — DTW·상관 혼합 금지, 설명 가능성 우선)
3. 동행 필터를 통과한 채널만 RMSE로 정렬

### 3.4 통과 후 결과 분류 (Track C)
t0 + h개월 시점의 3개월 이동중앙값 변화율 기준:
- 상승: +20% 이상 / 정체: ±20% 이내 / 하락: −20% 이하
- h = 3과 6 둘 다 보고. h=6 관측 불가 채널은 "미성숙"으로 별도 집계 (분모에서 빼되 개수 공개)

## 4. 트랙별 알고리즘 (가중 점수 없음 — 필터 + 단일 정렬)

### 4.1 Track C (먼저 실행 — 모든 해석의 앵커)
```
전수 풀 → 시계열 6mo+ → t0 존재 → h개월 후 분류
출력: n, 상승 X% / 정체 Y% / 하락 Z% / 미성숙 k개
```

### 4.2 Track A (동행)
```
필터: 현재 레벨 0.7~1.5 × L
    AND |α_ch − α_구비바| ≤ 0.3/월
    AND CV ≤ 0.25
정렬: 정규화 RMSE 오름차순 → 상위 10
출력: 동행 10개의 다음 3~6개월 실제 궤적 분포 = 구비바 예측 밴드
```

### 4.3 Track B (언니)
```
필터: t0 존재 AND t0+h에서 "상승" 분류
정렬: α 내림차순 → 상위 10 (사례 소개는 3~5)
v3.1 확장: 상승 그룹 vs 정체 그룹의 관측 가능 행동 차이
  (방송시간 변화, 편성 규칙성, 카테고리 전환 — 방송기록 데이터 필요)
```

## 5. 노이즈 처리

- 정수 반올림: 각 관측값 ±0.5 균등 노이즈로 slope 부트스트랩(1,000회) → **slope 95% CI**. CI가 겹치는 채널 간 순위 차이를 결론에 쓰지 않는다.
- 4~5개월 창은 CI가 커서 자연 탈락됨 — 이게 §2 최소 기간 상향의 정량 근거.

## 7. 클라이언트 리포트 출력 형식

```
① 분포 문장 (Track C): "당신 레벨(≈17명)을 지난 채널 n개 중,
   6개월 뒤 X%는 +20% 이상 성장, Y%는 정체, Z%는 하락했습니다."
② 예측 밴드 차트 (Track A): 동행 10개의 향후 궤적 범위 위에 구비바 현재 위치
③ 언니 사례 3건 (Track B): t0 정렬 궤적 + (v3.1) 행동 차이
```
①→②→③ 순서 고정 — 분포(현실) 먼저, 사례(희망)는 마지막.
