## 1. 케이스 참여 프로그램 (동의 연동 업그레이드): 실전 적용됨

| 레벨 | 동의 내용 | 혜택 |
|---|---|---|
| 없음 | 사례 활용 불가 | 광고된 패키지 그대로 |
| 1단계 | 채널명 비공개, 데이터·궤적만 사용 ("4개월 차 버튜버 사례") | 데이터 카드 월간 갱신 3개월 or 분기 재점검 1회 |
| 2단계 | 채널명 공개, before/after 사례 게재 | DELUXE 결제로 PREMIUM 구성 전체 |

**용어 주의**: 대외 설명에서 "실명 사례"라고 하지 말 것. 버튜버는 신상 노출로 오해함. **"채널명 공개"**로 표현하고, "본명·개인 신상은 어느 쪽이든 공개하지 않는다"를 먼저 명시.

**공통 조항**: 게시 전 원고 확인 필수 / 철회 자유 / 철회 시 기제공 혜택 회수 없음, 잔여 미제공분은 기본 구성으로 전환 / 완전 익명 활용은 보상 체계 밖(무보상 별도 동의).

**결정 시점**: 리포트 수령 후 결정 허용. 계약 시점에 뭐가 공개될지 모르는 상태로 판단시키는 것은 불합리. (유리아 케이스에서 적용)

**미성년 처리**: 2단계 선택 시에만 확인. 보호자 동의 필요. 선제 질문 금지(§2.7).

## 2. 두 경로 클로징

- A: PREMIUM 정가 (사례 활용 없음, 프라이버시 보전)
- B: DELUXE + 2단계 동의 → PREMIUM 구성

**목적**: 무조건 업그레이드는 PREMIUM 정가의 판매 이유를 소멸시킴. 두 경로로 나누면 정가 경로에 "프라이버시 프리미엄"이라는 이유가 생김.

**모순 방지 문구 필수**: PREMIUM을 권하지 않았는데 2단계 혜택이 PREMIUM이면 앞뒤가 안 맞아 보임. "있어서 나쁠 건 없지만 그것 때문에 굳이 공개하실 필요는 없다"를 반드시 붙일 것.

## 3. 가격 전환 고지 (신규 표준)

파일럿 특가를 쓰는 이상, 정식 전환 예정가(150/300/600k)를 클로징에서 구두 고지한다. 페이지에 적혀 있어도 상담에서 언급하는 것이 정직 포지셔닝에 정합.

**압박으로 쓰지 않기 위한 짝 문장 필수**: "지금 서두르시라는 얘기는 아닙니다. 필요 없는 걸 미리 사두는 게 이득인 경우는 별로 없습니다. 다만 판단 재료는 다 드리고 싶어서요."

백설호 후속 메시지에는 이 고지가 누락됨. 향후 템플릿에 포함.

## 4. 리퍼럴 프로그램 (미정의 → 조건 필요)

유리아 상담에서 즉흥 언급됨: "다른 스트리머 소개 → 그분 DELUXE 이상 결제 시 두 분 다 PREMIUM 업그레이드"

**정의 필요 항목**
- 상한: 1인당 최대 2~3건 (캐파 관리)
- 기간: 파일럿 기간 한정
- 지급 조건: 소개받은 쪽 **결제 완료 시점**에만 (문의·상담만으로는 불가)
- 보상 형태 재검토: PREMIUM 전체 대신 경량 자동화 혜택(카드 갱신, 분기 점검 1회)도 검토. 단 PREMIUM 실노동이 연 15~23시간으로 추정보다 낮아 현행 유지도 가능

**타이밍 규칙**: 상담 클로징에서 꺼내지 말 것. 아직 결과물을 받지 못한 사람에게 소개를 요청하는 구조가 됨. **리포트 전달 후 만족 확인 시점**이 정위치.

## 5. PREMIUM 실노동 추정 (캐파 판단 근거)

| 구성 | 시간 |
|---|---|
| 실행 우선순위 설계 | 2~3h |
| 4주 모니터링 + 체크인 4회 | 4~8h |
| 분기 재점검 3회 | 6~9h |
| 전략 리빌딩 1회 | 3h |
| **합계** | **15~23h, 1년 분산** |

"1년 동행"은 기간 표현이지 시간량이 아님. 상담에서는 **"1년에 걸쳐 8번 만납니다"처럼 횟수로 말할 것** (기대 관리).

**진짜 리스크는 시간이 아니라 분산 관리**: 분기 점검은 3개월 간격이라 양쪽 다 잊기 쉬움. 클라이언트별 리마인더 필수. 미이행 시 신뢰 훼손 + 분쟁 소지.

**자동화 여지**: 분기 점검은 파이프라인 재실행이라 회당 2~3h → 1h 이하로 축소 가능. 케이스 누적 시 PREMIUM이 마진 상품이 됨.

## 6. 세그먼트별 클로징 논리

| 고객 상태 | 유효한 프레임 |
|---|---|
| 이미 수익 발생 중 | **회수 논리**. "월 X만원이 Y% 늘면 Z주에 회수" (구비바 PREMIUM 샘플이 근거) |
| 수익화 이전 | **기회비용 프레임**. "지금 안 하면 잘못된 방향으로 1년을 쓴다" (유리아 노마이크 15시간에 팔로워 1명이 실례) |

회수 논리를 수익화 이전 고객에게 쓰면 성립하지 않음. 유리아 케이스에서 확인.

## 7. 무료 상담 부담 관리 (신규)

상담이 길수록 클라이언트가 빚진 느낌을 가짐. 백설호 73분, 유리아 108분.

**양방향 작용**: 호혜성은 회피(체리피커로 보이기 싫어 회피)와 상환(받았으니 갚는다) 양쪽으로 작동. 관계가 좋으면 상환 쪽, 어색하거나 압박이 있으면 회피 쪽. **부담을 완전히 제거하려는 시도도 역효과 가능** (면제 자체가 또 하나의 호의).

**실무 규칙**: 상담 중 부담 해제 문장을 과하게 넣지 말고, 클로징에서 압박도 면제도 없이 **다음 단계만 명확히** 제시. 결정 언급은 최소화.

## 8. 채팅 상담 vs 통화 상담

| | 통화 | 채팅 |
|---|---|---|
| 소요 | 73분 | 108분 (1.5배) |
| Q0 진술 | 4분 무개입으로 풍부 | 짧아지기 쉬움 → **사전 합의 필요** ("길게 답해달라") |
| 자료 전달 | 화면 공유 | 파일 첨부가 자연스러움 (오히려 유리) |
| 클로징 | 즉석 문답 가능 | 기록으로 남아 재독 가능 (유리) |
| 실시간 데이터 수집 | 어려움 | **가능** (유리아 케이스에서 상담 중 100개 방송 분석 투입) |

**채팅 운영 규칙**: 3~4줄 블록, 질문 후 대기, 답변에 대한 첫 반응은 반드시 즉흥(준비 블록만 연달아 보내면 티남), 클로징 메시지는 정보 하나씩 분리.
