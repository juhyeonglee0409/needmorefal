1. What was done
백테스트와 방향을 뒤집어, 999채널×53주 데이터에서 규칙 후보를 역추출. 과적합 방지 설계: 발굴 창(t=4..20 채널-주 풀링)에서 후보 탐색 → 검증 창(t=30, 채널당 단일 스냅샷 = 독립 표본)에서 같은 부호+permutation p≤0.05 재현 확인. 성과 정의는 백테스트와 동일(전방 12주 팔로워 상대 성장 α). 지표 9종 검사.

2. 결과 (재현 통과 순)
- **성장 관성 (momentum_fol)**: 직전 4주 팔로워 성장 → 이후 12주 초과 성장. ρ=0.65/0.63(발굴/검증). 최강 신호.
- **뷰어십 효율 (efficiency = 평시청/팔로워)**: ρ=0.48/0.50. "실시청 대비 팔로워가 적으면 따라잡기 성장" — 방법론 6축의 전환율 축이 예측 신호로 실증됨.
- **체급 역상관 (follower_log)**: ρ=−0.44/−0.31. 세그먼트 내에서도 작을수록 상대 성장 빠름 (구조 효과).
- **채팅 참여율 (chat_rate = 채팅/시청자)**: ρ=0.17/0.10 (p=0.009). 약하지만 재현.
- 기각/불안정: retention(재확인 — 백테스트와 일관), airtime(ρ와 quintile spread 부호 불일치 = 비단조·불안정), consistency, air_cv.
- **조합 규칙 (검증 스냅샷, n=639, 기저 49.3%)**: 효율 상위25%+관성 상위25% → P(초과성장) 90.0% (n=80) / 둘 다 하위25% → 6.8% (n=74). 리텐션 하한이 못 하던 "경보" 역할을 이 조합이 대신할 수 있음.
