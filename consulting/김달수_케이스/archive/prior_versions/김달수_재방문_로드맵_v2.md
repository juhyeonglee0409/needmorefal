# 김달수 1만 팔로워 로드맵 v2

### 정체성 기반 재방문·정착 전략

> 버전: 로드맵 v2 (마일스톤 전원 리뷰 + 정체성 재정렬) · 작성 2026-05-28 · 상태: **중간 정리 — 데이터 재검증 전** · 사실 기반: project.json (claim C1–C31)
> v1→v2 핵심: ① 정체성 교체("착하게 롤하기/편안함" → "진심·사촌동생·정붙음/양지") ② 콘텐츠 알맹이 공백 메움 ③ 커뮤니티를 부차 레버 → 핵심 엔진으로 승격 ④ 4월 진단 정정(노방종 착시) ⑤ 측정 지표 재정의(평청 → 방송시간 보정)
> 작성 주체: 스트리머팀(에디터+패널). 컨설팅팀·구현팀과 분리된 전략·로드맵 문서.

## 0. 한 장 요약

- **정체성(고정점).** 롤에 진심이라 처음엔 쎄 보이지만 알고 보면 여리고 귀여운 — 게임 보러 왔다가 사람에 정붙는, 챙겨보게 되는 사촌동생 같은 양지 채널. (본인+GPT 교차검증, A급)
- **전략 한 줄.** 새 사람을 더 끌어오는 게 아니라(이미 강점), **팔로우한 사람이 "정붙어 다시 오게"** 만든다. v1의 "편안함"보다 능동적 — *관계·챙김*이 엔진.
- **진단(중간).** 발견·전환은 코호트 1위 수준의 강점. 약한 곳은 "팔로우 후 재방문" 구간. 단 4월 "급락"의 상당 부분은 **노방종(24h 방송) 측정 착시**였음이 밝혀져, 하락 크기는 재계산 대상.
- **검증 보류.** "항상 켜진 아지트/장시간 방송"이 자산인지 평청만 깎는지는 데이터로 판정(O14). 김달수 선호이나 정체성 아닌 전략 가설.

## 1. 목표와 판정 기준 (불변)

**목표 1문장.** 김달수의 정체성 위에 비율(보정 지표 기준) 건강선을 유지하며 진성 누적을 만들고 1만 팔로워 마일스톤에 도달한다.

| 순위 | 지표 | 의미 |
|---|---|---|
| 1차 KPI | 비율(평청÷팔로워) 건강선 유지 | **단, 지표는 노방종 보정판으로 재정의 — §4** |
| 후행 마일스톤 | 팔로워 1만 | 비율과 충돌 시 비율 우선 |
| 고정점 | 진심·사촌동생·정붙음·양지 | 어떤 레버도 이걸 깎으면 기각 |

**"진성"의 정의 (C31).** 실력·외모 보러 오는 사람이 아니라, **정붙어 챙겨보는 사람.** 시청자 역할 = 사촌동생을 챙기는 손위. 이 정의가 KPI의 알맹이다.

## 2. 진단 — 무엇이 새 정체성으로 바뀌었나

**깔때기와 누수 지점(유지).**
```
발견(강점) → 팔로우 전환(강점, 코호트 1위) → 〔재방문·정착 ← 여기서 샌다〕 → 정붙은 코어
```

**4월 "급락" 정정(중요).** 4월 비율 하락(−0.78%p)으로 LCK·개별사건을 따졌으나, 4/27~30 24시간 노방종 방송으로 방송시간 분모가 폭증해 **평청만 깎인 측정 착시(층3)**였음. 방송별 최고동접 평균으로 보면 3월(106) 피크 후 4·5월(90)은 1·2월 수준 복귀 — "폭락"이 아니라 "3월 고점 + 노방종 착시의 합성". 재방문 누수 자체(5개월 팔로워+23%/평청−20%)는 여전히 시사되나, **크기는 보정 지표로 재계산해야 신뢰 가능.**

**콘텐츠 알맹이(공백 메움).** "사촌동생"은 관계를 정의했으나 "무엇을 하는 채널"이 비어 있었음. 답: 정체성 안에 있음 — **"진입=게임, 잔류=사람"이 곧 콘텐츠 공식.** 솔랭을 하되, 게임이 *사람 리액션(티키타카·억까·캐리 반응)의 무대*가 되는 방송. 새 코너·세계관을 만드는 게 아니라 *지금의 솔랭을 사촌동생의 무대로 프레이밍.* (본인 부담 최소, "진심" 정체성과 정합)

## 3. 로드맵 — 정체성 정렬 레버

> v1과 달리 **커뮤니티가 핵심 엔진**(정붙음=정체성 중심). 모든 레버는 "편하게 해주기"가 아니라 "정붙게 하기" 기준.

### Phase A — 토대 (재방문 습관)

| 레버 | 무엇을 | 정체성 정렬 | 가드레일 |
|---|---|---|---|
| **L1 예측 가능성** | 시청자가 "언제 오면 있는지" 알게 | 고정 시간 vs 상시(아지트)는 **O14 데이터 후 확정** | 번아웃 — 무리한 빈도/시간 금지 |
| **L2 시작 신호** | 방송 켤 때 확실히 알림(앱+SNS) | 사촌동생 "나 시작함" 톤 | 과한 푸시 금지 |
| **L7 연속 훅** | 방송 간 이어지는 맥락(다음에 뭐 할지) | "진심" 서사의 연속성 | 억지 연출 금지 |

### Phase B — 정붙음 엔진 (커뮤니티 = 승격된 핵심)

| 레버 | 무엇을 | 정체성 정렬 | 가드레일 |
|---|---|---|---|
| **L5 관계 호명** | 단골을 알아보고 챙김 — "사촌동생-손위" 관계 형성 | 시청자가 "내가 챙겨보는 사람"이라는 역할 인식(C31) | 자연스러움, 감정노동 상한 |
| **L6 단골 의례** | 내부 밈·고정 호칭·"우리끼리 아는 것" | 사촌동생네 가족 같은 소속감 = 정붙음의 핵심 | 신규 진입장벽화 경계 |
| **L4 카페 = 비동기 아지트** | 방송 안 할 때도 정 붙어 있는 공간 | "정붙음"의 방송 밖 연장 | 관리 부담 상한 |

### Phase C — 반전 노출 (밖에서 안 보이는 매력 꺼내기)

| 레버 | 무엇을 | 정체성 정렬 | 가드레일 |
|---|---|---|---|
| **L9-a 진입 클립** | 게임 하이라이트(억까·캐리·리액션) | 진입=게임, 카테고리 노출 | 자극적 편집 금지 |
| **L9-b 잔류 증명 클립** | 사촌동생 매력(반전·티키타카) | "이 사람 정붙겠다"를 밖에서 보이기 | — |
| **L3 오프닝/L8 코너** | 솔랭을 "사람 무대"로 프레이밍 | 진심+사촌동생 톤 | **연출 상한** — 과하면 거부권 |

### 기각 유지

**외모 기반 발견(K6).** 정체성("진심·사촌동생·양지")과 정면 충돌 + 데이터상 저몰입 유입(안 남는 층) 유발. 기각 유지.

## 4. 측정 — 노방종 보정 (v1에서 전면 교체)

**"평청"은 더 이상 단독 1차 지표로 쓰지 않는다.** 노방종/장시간 방송이 방송시간 분모를 키워 평청을 왜곡(4월 착시의 원인). 대신:

| 지표 | 왜 |
|---|---|
| **방송별 최고동접 평균** | 노방종 면역 — 방송시간 무관 |
| **액티브시간 평청** | 죽은 시간(새벽 등) 제외 후 평균 |
| **중앙값 동접** | 긴 꼬리(저시청 시간)에 강함 |
| 고정/반복 시청자 비율 | 정붙음 = 핵심이므로 직접 추적 |

**방송 단위 데이터로 받는다.** 엔터 "방송 기록"(방송 단위)으로 받으면 일별 집계의 노방종 착시가 원천 차단됨. 기준선은 데이터 재수집 후 스냅샷.

**측정의 1차 데이터 한계.** 치지직 스튜디오는 집계 요약만 제공(신규/재방문 분해·유입경로 없음). 재방문 직접 측정 불가 → 프록시 의존. 지속률(직전 5.01%)·고정시청자 비율로 간접 확인.

## 5. 열린 항목 / 게이트

이 문서는 **데이터 재검증 전 중간 정리**다. 다음이 v3에서 확정/수정한다.

1. **O0 지표 재정의** — 보정 지표로 비율·추세·outlier 전면 재계산. (4월 착시 발견으로 기존 수치 신뢰도 하락)
2. **O14 아지트 검증** — 장시간 방송이 정착에 +인지 평청만 깎는지. **지속가능성(번아웃)과 함께** 판정. 김달수 선호이나 데이터 대기.
3. **비교군 재설계** — 새 정체성 렌즈(친근·소통형 롤, 실력파·외모파 아님)로 코호트 층화. 1만~3만 구간 포함(생존자 편향 교정).
4. **콘텐츠 알맹이 검증** — "솔랭=사람 무대" 프레이밍이 실제 정착을 만드는지.
5. **A3** — '달수보는 곳' 유튜브가 깔때기냐 아카이브냐.
6. **레버는 가설.** 선행지표로 1차 검증 후 확정.
7. **XGPS 외부 검토** — 확정 전 권고(자기 산출물 방어 편향 보완).

## 6. 거버넌스 / 지속가능성 경보

- **충돌 중재:** decision_priority — 윤리·가이드라인 > 정체성 > 비율 > 1만 > 속도.
- **거부권:** 포지셔닝 디렉터(정체성 침해), 지속가능성 코치(번아웃·발견압력).
- **번아웃 경보(신규).** Phase B 레버(호명·의례·관계 챙김)는 감정노동. "정붙음" 강화 × "장시간(O14)"은 소진 빠른 조합. 레버마다 *지속 가능한 강도 상한* 필수. 비율에 좋아도 김달수가 못 버티면 기각.
- **기록:** 모든 결정·폐기·반론은 project.json 레지스터. 근거 사실 C1–C31.
