## 축 1. 신뢰 신호

### 관찰

- 리뷰 0건, 총 거래 건수 "-", 만족도 "-", 평균 응답시간 "아직 몰라요", 개인회원, 세금계산서 발행 불가 — 크몽이 노출하는 신뢰 지표 전 항목이 공란 또는 마이너스 신호.
- 경력 사항: "이어서봄·전략기획팀·팀장·1년.2개월 프리랜서·1년.8개월" — 표기가 깨진 것처럼 보이고("1년.2개월"), 스트리밍 도메인과의 연결이 드러나지 않음.
- 전문가 소개: "AI 분석 방법론을 연구하는 독립 연구자… 프리프린트 4편… 빠르고 부담 없는 가격" — 연구자 정체성 중심, 타겟(소규모 스트리머)의 신뢰 언어와 어긋남.
- 익명 사례(치지직 A님: 동급 131명 중 상위 10위권, 최고 동시시청자 227% 성장, 잔류 지표 중앙값 65%)는 구체적이고 강함. 단 "전체 리포트 예시는 크몽 메시지로 문의" — 핵심 증거를 페이지 밖에 둠.
- **내부 모순 발견**: 가격표는 수정 횟수 3/6/9회, 본문 "수정 및 재진행" 섹션은 1/2/3회.
- 가격표에 STANDARD 포함 "강의·컨설팅 2회 × 120분" — 요약 리포트 포지션의 STANDARD에 240분 상담이 붙어 있음. 의도인지 설정 오류인지 페이지만으로는 판단 불가. (가격 판정 아님 — 구성 정합성 문제.)

### 진단

리뷰 0은 못 없애지만, 통제 가능한 신호 4개가 방치돼 있다: 응답시간, 페이지 내 증거, 텍스트 정합성, 프로필 언어. 특히 "데이터의 정확성"을 파는 서비스에서 자기 페이지의 숫자가 서로 안 맞는 것(수정 횟수 모순)은 포지셔닝 자체를 훼손한다. 경쟁 리스팅은 전부 "65만 유튜버", "Best Seller" 같은 권위 숫자로 신뢰를 선점하는데, 이 리스팅이 쓸 수 있는 유일한 숫자는 방법의 숫자(비교군 100여 개, 사례 수치)와 리포트 실물이다. 리뷰 0 상태에서 신뢰의 실질 대체재는 "결제 전 위험 제거" = 무료 사전 확인.

### 액션 (첫 5건 직결)

1. **수정 횟수 모순 즉시 통일** (오늘, 5분). 3/6/9든 1/2/3이든 실제 제공 의도로.
2. **STANDARD 120분×2회 표 재확인** — 제공 의도가 맞으면 본문에 "STANDARD에도 120분 리뷰 2회 포함"을 혜택으로 명시, 오류면 수정.
3. **응답시간 지표 확보**: 10~18시 문의 1시간 내 응답 체제. "아직 몰라요"가 "1시간 이내" 배지로 바뀌는 것이 이 단계에서 가장 싸게 얻는 신뢰 신호.
4. **리포트 증거를 페이지 안으로**: "전체 리포트 예시는 메시지로 문의" 문구를 "아래 상세이미지가 실제 리포트 샘플" 안내로 교체하고, 사례 A의 수치와 상세이미지 샘플이 서로 참조되게 정렬.
5. **프로필 첫 문장 교체**: "치지직·SOOP 채널 100여 개 비교군 데이터로 내 채널의 위치를 진단합니다"류 타겟 언어 선행, 연구자·프리프린트는 뒷받침으로. "빠르고 부담 없는 가격" 문구 삭제 (셀프 디스카운팅).
6. **첫 5건 리뷰 회수 스크립트 준비**: 납품+리뷰 시점에 정중한 리뷰 요청 1회. 보상 제안은 크몽 규정 위반 소지 — 금지.

## 축 2. 서비스 설명

### 관찰

- 본문은 문제 주도형 롱폼으로 완성도 높음: 후킹 질문("팔로워 대비 평균 시청자, 몇 명이면 잘하는 걸까요?"), 통계 착시 3가지, 실사례 수치, FAQ, 절차, 준비사항까지 갖춤.
- 무료 사전 확인 블록이 본문 중간과 끝에 위치 — 첫 화면에는 없음.
- 제목 "데이터 기반 스트리머 성장 컨설팅": 차별 요소(동급 100개 비교, 내 위치)가 제목에 실리지 않음. 검색 결과에서 경쟁자는 "65만 유튜버를 만든…", "35만 유튜버의…", "Best Seller 전문가의…"로 숫자를 제목에 박음.
- 치지직/SOOP 키워드가 본문에만 있고 제목에 없음.
- 캐러셀(다크+녹색, 데이터 테이블)은 포지셔닝과 일치 (시각 내용은 operator 컨텍스트 기준).

### 진단

도착한 방문자를 설득하는 힘은 이미 충분하다. 병목은 두 가지: (a) 도착 전 자산 — 제목·썸네일이 차별 숫자를 안 싣고 있어 검색 결과 화면에서 권위 숫자 리스팅에 밀림, (b) 전환 목표 오설정 — 리뷰 0 상태의 현실적 퍼널은 "구매하기"가 아니라 "문의하기(무료 사전 확인)→결제"인데, 페이지가 직접 구매 구조로 짜여 있음. 첫 5건은 거의 확실히 문의 경유로 온다. 문의 전환율이 곧 판매 전환율.

### 액션 (첫 5건 직결)

1. **무료 사전 확인을 본문 최상단으로**: "결제 전, 채널 주소와 고민 한 줄만 보내면 분석 가능 여부를 무료로 확인해드립니다"를 첫 스크롤 안에 배치. 페이지의 주 CTA를 '문의'로 재설정.
2. **제목에 방법 숫자+플랫폼 키워드**: 예: "치지직·SOOP 동급 100개 채널과 비교하는 스트리머 성장 진단" (크몽 제목 글자수 한도 내 조정).
3. **캐러셀 1장 헤드라인을 질문형으로**: "내 채널, 동급 100개 중 몇 위일까?" + 사례 수치(131명 중 상위 10위권) 활용.
4. **사례 즉시 증식**: 첫 1~2건 완료 즉시 사례 2·3을 본문에 추가. 리뷰가 쌓이기 전까지는 사례가 리뷰를 대신한다.

## 축 3. 마켓플레이스 맥락

### 관찰

- 카테고리: 창업·사업 > 일반 경영 자문 > 성장 전략. 이 카테고리의 브라우징 구매자는 사업자/스타트업 — 소규모 스트리머가 들어올 동선이 아님.
- 스트리머/유튜브 컨설팅 경쟁 리스팅은 대부분 유튜브·마케팅/레슨 계열 카테고리에 위치.
- "스트리머 컨설팅" 검색 지형: 데이터 진단형 직접 경쟁자는 사실상 없음. 경쟁은 (a) 대형 유튜버 권위형 컨설팅(65만/35만 구독자), (b) 시청자수·구독자 구매형 "채널관리" 서비스 두 부류.
- 실수요 검색어는 "유튜브 컨설팅"에 몰려 있고, "치지직/스트리머 컨설팅"은 롱테일이지만 경쟁이 얇음.

### 진단

포지셔닝(동급 비교군 데이터 진단)은 크몽 안에서 유일에 가깝다 — 차별화가 아니라 발견성이 문제다. 타겟은 이 카테고리에 안 들어오고, 검색에서는 권위 숫자 리스팅과 봇 서비스 사이에 섞인다. 봇/구매형 서비스와 같은 결과 화면에 노출되므로 "진짜 데이터 진단"임이 썸네일 단계에서 즉시 구분되어야 한다.

### 액션 (첫 5건 직결)

1. **검색태그·제목에 플랫폼 키워드 선점**: 치지직, SOOP, 버튜버, 트위치 등 — 유튜브 중심 경쟁자들이 안 덮는 영역. 즉시 실행 가능하고 리스크 없음.
2. **카테고리 이동은 데이터 본 뒤 판단**: 크몽 판매자 대시보드의 노출/유입 통계를 1~2주 관찰 후, 유입이 검색 중심인지 카테고리 중심인지 확인하고 이동 여부 결정. 이동은 노출 리셋 리스크가 있어 operator 판단 사항.
3. **신규 리스팅 초기 노출 구간 활용**: 크몽 정렬에 신규등록순이 있고 신규 리스팅에 초기 노출 기회가 있는 것으로 보임(정확한 가중치는 미검증). 이 구간에 응답속도·문의 응대 품질을 최대로.
4. **구분 신호 전면화**: FAQ에만 있는 "시청자 수 증가 보장 아님, 데이터 진단 서비스" 포지션을 본문 상단/썸네일 문구로 승격 — 봇 서비스와의 즉시 구분이 신뢰로 전환됨.
