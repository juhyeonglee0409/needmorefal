# §8 종합 실행 로드맵

**1부(§1-§6)와 2부 §7의 분석 결과를 종합한 단계별 실행 계획이다.**

---

| 지표 | 현재 값 | 코호트 위치 | 판정 |
|------|---------|------------|------|
| 팔로워 | 728 | Layer B 하위 | 체급 부족 |
| 평균시청자(avg) | 18 | 동체급 상위 31% | 강점 |

## 8.2 3단계 로드맵

### Phase 1: 기반 다지기 — 리텐션 개선 (1~3개월)

**목표:** 리텐션 26.9% → 35%+ / 잔류율 0.65+ 유지

이 단계의 핵심은 "스파이크 시청자가 일상 방송에 돌아오게 만드는 것"이다. 피크 집객력은 이미 충분하다(상위 14%). 문제는 피크와 일상의 낙차.

| 액션 | 근거 | KPI |
|------|------|-----|
| 일상 방송 시작 시 전회 하이라이트 리캡 (30초~1분) | 스파이크→일상 연결 고리 부재가 리텐션 병목 (§6) | 일상 avg 변화 |
| 주간 편성표 공지 (치지직 공지 + 커뮤니티) | 시청자가 "다음 방송이 언제인지" 모르면 이탈 | 공지 후 복귀율 |
| 스파이크 방송 종료 시 다음 일상 방송 예고 | 피크 시청자에게 "다음 방송에도 올 이유" 제공 | 피크 후 24h 내 복귀율 |
| 오후 12-15시 편성 유지 | 최고 성과 시간대 (§3.3) | — |
| 겸업 전략(종합게임+버추얼) 유지 | 시청자 확보 구조적 이점 (§5.1) | — |

**하지 않을 것:**
- 방송 시간 추가 투입 (이미 100%ile, 추가 효과 없음)
- 스파이크 이벤트 편중 (일상 바닥 올리기가 우선)
- 유튜브 재시작 (아직 이름)

**체크포인트 (3개월 시점):**
- 리텐션 35%+ 도달 → Phase 2 진입
- 리텐션 30-35% → Phase 1 연장 (최대 2개월)
- 리텐션 30% 미만 → 전략 재점검 (방송 구조 자체 변경 검토)

---

### Phase 2: 도달 확장 — 유튜브 재시작 + 팔로워 성장 (4~8개월)

**목표:** 유튜브 clip/highlight 월 8회 업로드 체계 구축 / 팔로워 1,000+ 도달

리텐션이 35%를 넘으면, 새로 유입된 시청자가 정착할 확률이 높아진다. 이 시점에 도달 채널(유튜브)을 가동한다.

| 액션 | 근거 | KPI |
|------|------|-----|
| 유튜브 콘텐츠 전환: full_vod → clip/highlight | full_vod 잔류율 최하위 (§7.4), 상위밴드 69%가 clip/highlight | 영상당 조회수 |
| 기존 채널(@GOOBIBA02) 리브랜딩 | 새 채널보다 367개 아카이브 활용이 효율적 (§7.5) | — |
| 주 2회 업로드로 시작 → 월 8회 목표 | 상위밴드 중앙값 월 8회 (§7.3) | 월간 업로드 수 |
| 방송 하이라이트 클립 3-5분 편집 | clip(39.7%)이 가장 보편적 전략 | YT 구독자 증가율 |
| 유튜브 → 치지직 유입 경로 설치 | 영상 설명란 + 엔드카드에 치지직 링크 | YT→치지직 유입 추적 |

**하지 않을 것:**
- 풀 VOD 업로드 재개 (검증된 비효율 전략)
- 유튜브 오리지널 콘텐츠 제작 (대형 채널 전용, §7.4)
- 업로드 빈도를 무리하게 올리기 (품질 > 양)

**체크포인트 (8개월 시점):**
- 팔로워 1,000+ & YT 구독자 500+ → Phase 3 진입
- 팔로워 900-1,000 → Phase 2 연장
- 리텐션이 다시 30% 아래로 하락 → Phase 1로 회귀

**경보 하한 (전 기간 적용, §4.4):**

| 경보 지표 | 기준 |
|-----------|------|
| 잔류율(방송 내) < 0.60 | 확정 강점 상실 |
| 리텐션(방송 간) < 20% | 구조적 악화 |
| peak < 21 at 팔로워 1,000+ | 체급-시청자 불일치 |

---

### Phase 3: 변곡점 돌파 — 팔로워 1,500 (9~18개월)

**목표:** 팔로워 1,500 변곡점 돌파 / avg≥14 확률 83% 구간 진입

| 마일스톤 | 조건 | 의미 |
|---------|------|------|
| 팔로워 1,000 | Phase 2 완료 | 4자리 진입 |
| 팔로워 1,500 | **변곡점** | avg≥14 확률 28%→83% (§5.3) |
| 팔로워 2,500 | 1차 목표 상한 | avg≥20 확률 44% |
| 리텐션 40%+ | Phase 1 목표 지속 | 동체급 상위 50% |
| YT 구독자 1,000+ | 도달 채널 작동 | 유의미한 외부 유입원 |

**이 단계의 핵심:**
- Phase 1-2에서 구축한 리텐션 기반 + 유튜브 유입 경로가 복합적으로 작용
- 팔로워 1,500 이상에서는 코호트 데이터상 avg≥14가 자연스러운 수준
- 이 시점에서 2차 목표(팔로워 10,000) 재평가

## 8.3 타임라인 요약

```
Month 1-3     Phase 1: 리텐션 개선
              ├─ 일상 방송 바닥 올리기
              ├─ 스파이크→일상 연결 강화
              └─ 체크: 리텐션 35%+?

Month 4-8     Phase 2: 유튜브 재시작 + 성장
              ├─ clip/highlight 전환
              ├─ 월 8회 업로드 체계
              └─ 체크: 팔로워 1,000+?

Month 9-18    Phase 3: 변곡점 돌파
              ├─ 팔로워 1,500 목표
              ├─ 리텐션 40%+ 유지
              └─ 2차 목표 재평가
```

**현실적 시간 감각:** 현재 성장률(연 +51%)이 유지되면 팔로워 1,500 도달은 약 18개월. 리텐션 개선 + 유튜브 효과로 성장률이 2배(연 +100%)로 가속하면 약 12개월. 이 로드맵은 12~18개월 범위를 상정한다.

# §9 결론

## 전체 요약

이 보고서는 구비바 채널의 현재 위치를 576채널 VTuber 코호트 + 271채널 상위밴드에서 정량적으로 진단하고, 성장 경로를 도출했다.

**1부(§1-§6)의 핵심:**
- 4강 2약 구조 확인: 전환율(72%ile)·피크(76%ile)·잔류율(상위 14%)·효율(73%ile)은 강점. 팔로워(28%ile)와 리텐션(25%ile)이 병목.
- "팔로워 under-indexed, 콘텐츠 over-indexed" — 콘텐츠 품질로 체급 부족을 보상하는 구조.
- 방송량 추가 투입은 해답이 아니다(방송시간-시청자 음의 상관).
- 겸업 전략은 구조적 이점이 있다.
- 팔로워 1,500이 변곡점이다.

**2부 §7의 핵심:**
- 상위밴드의 93%가 유튜브를 보유. 유튜브는 표준 인프라.
- 그러나 유튜브 지표와 치지직 리텐션 사이 상관은 없다 (r≈0).
- 구비바의 현재 유튜브 전략(full_vod)은 가장 비효율적인 유형.
- 유튜브 재시작은 필요하지만, 리텐션 개선이 선행되어야 한다.

**종합 결론:**

구비바 채널은 "못하는 채널"이 아니라 "아직 풀리지 않은 채널"이다. 콘텐츠 품질 지표가 코호트 상위 15%에 위치하는데도 성장이 더딘 이유는, 피크 시청자가 일상으로 전환되지 않는 리텐션 구조에 있다. 이 병목 하나를 해소하면, 기존 강점(잔류율·전환율·효율)이 성장 동력으로 전환될 수 있다.

실행 순서는 명확하다: **리텐션 개선(P0) → 유튜브 재시작(P1) → 변곡점 돌파(P2).** 이 순서를 지키는 것이 이 보고서의 핵심 권고다.
