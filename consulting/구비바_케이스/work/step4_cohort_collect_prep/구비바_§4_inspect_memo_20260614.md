## 원래 ExecutionProtocol 대비 변경점

| 항목 | 원래 (일반 랭킹) | 새 (카테고리 CSV) |
|---|---|---|
| 소스 | 전체 카테고리 상위 400ch | 롤 전용 10,000ch |
| 카테고리 필터 | 디테일 페이지 수집 필요 (Task 4) | **이미 필터됨** |
| 플랫폼 필터 | 수집 후 로컬 | CSV 전 필터 가능 또는 수집 후 로컬 |
| 요청 수 | 120-170 | CSV 1건 + 팔로워 보강 N건 |
| 팔로워 수 | Task 4-5에서 수집 | 디테일 페이지에서 보강 |
| 버추얼 분리 | Task 3 별도 수집 | 태그 필터로 분리 가능 |

### 핵심 이점
1. **카테고리 사전 필터링**: 롤 전용 10,000명 → 카테고리 enrichment 불필요
2. **대규모 모집단**: 400ch → 10,000ch로 20배 확대
3. **CSV 일괄 다운로드**: 100페이지 순회 불필요
4. **버추얼 태그 필터**: 별도 수집 없이 태그로 분리

### 남은 작업
1. CSV 다운로드 → 컬럼 구조 확정
2. 피크밴드 필터링 (최고시청자 74-296)
3. 치지직 플랫폼 필터링
4. 팔로워 보강 (피크밴드 해당자 디테일 페이지)
5. ExecutionProtocol 문서 일괄 리바이즈
