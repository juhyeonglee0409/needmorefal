# §6 상위 참조 밴드 수집 스펙

**용도:** §6 목표 트레이드오프 — "1만+평청200" 목표 지점의 실측 데이터  
**성격:** peer 코호트가 아닌 **목표 참조 밴드**. §4 코호트(323ch, ~5,579)와 분리.  
**작성:** 2026-06-16

---

## 수집 대상

| 항목 | 값 |
|---|---|
| 플랫폼 | 치지직 |
| 카테고리 | 종합게임 + 버추얼 (기존 T1/T2와 동일 기준) |
| 팔로워 범위 | **10,000 이상** (상한 없음) |
| 최소 채널 수 | **20~30ch** (상한 없음, 가능한 한 많이) |
| 구간별 최소 | 10k-20k: 8ch+, 20k-50k: 5ch+, 50k+: 있는 만큼 전부 |

## 필요 컬럼

기존 코호트와 동일한 지표. 채널당 1행 (채널 레벨 집계):

```csv
channel_name,channelId,channel_url,follower,categories,is_general_game,is_virtual,peak_max,peak_p95,peak_median,peak_recent_median,avg_median,avg_recent_median,stream_hours,ts_weeks,band
```

### 컬럼 정의 (기존 코호트와 동일)

| 컬럼 | 정의 |
|---|---|
| peak_max | 전체 방송 중 최고 시청자 최대값 |
| peak_p95 | 전체 방송의 최고 시청자 95번째 백분위 |
| peak_median | 전체 방송의 최고 시청자 중앙값 |
| peak_recent_median | 최근 8주 방송의 최고 시청자 중앙값 |
| avg_median | 전체 방송의 평균 시청자 중앙값 |
| avg_recent_median | 최근 8주 방송의 평균 시청자 중앙값 |
| stream_hours | 총 방송 시간 (시간 단위) |
| ts_weeks | 관측 기간 (주 단위) |

## 저장 위치

```
data/cohort/collected/cohort_ref_upper_band.csv
```

## 사용 방식

- §4 코호트와 **병합하지 않음** (peer가 아니므로)
- §6.2 도달 가능 범위 추정에서 **방법 C (상위 참조 밴드 실측)**으로 사용
- "팔로워 X일 때 avg/peak은 실제로 얼마인가" 확인용
- 핵심 질문: **avg 200이 달성되는 팔로워 구간은 어디인가**

## 주의

- 대형 채널은 콜라보·대회·레이드 등으로 peak이 크게 튀는 경우가 많음 → peak_median과 peak_max의 괴리가 클 수 있음
- 버추얼 대형 채널은 사무소(기업) 소속이 많아 개인 운영 채널과 구조가 다름 → 참고 수준으로만 사용
