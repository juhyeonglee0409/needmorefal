§1 용어 정의
지표 정의 및 산출 기준

§4 심층 진단
6개 하위 분석 — 효율 커브·잔류율·전환율·카테고리·성장 경로
방송시간 축소 시 잔류율 개선 여지가 있으며, 전환율은 자연 수렴대 진입 전.

§4.1 효율 커브 — U자형

방송시간 30h 이하와 150h+ 양극에서 효율(뷰어십/팔로워)이 높고, 중간대에서 낮아지는 U자 구조. 본 채널(162.7h, 효율 2.99)은 오른쪽 끝에 위치. 극단 방송시간이 효율을 밀어올리는 것이 아니라, 뷰어십 총량을 팔로워로 나눈 결과.

§4.2 잔류율 — 방송시간 역관계

150h+ 그룹 잔류율 중앙 0.245, 80~150h 그룹 0.299, 30~80h 그룹 0.362. 본 채널 0.418은 150h+ 내에서 이례적으로 높지만, 동급생 중앙 0.645 대비 절대 수준 하위. 코호트 밴드 분포 기반 — 동일 채널 시계열 검증은 아님.

§4.3 전환율 — 자연 희석 전

50K~100K 밴드 전환율 중앙 1.35%, 100K+ 1.56%. 현재 1.84%는 수렴대 진입 전이라 MS1(avg 120) 달성 시에도 유지 가능 추정.

§4.4 LoL 카테고리 내 위치

LoL 상위 100 최저 avg 346명. 현재 69명은 100위권 밖. 동일 카테고리 내 5배 성장이 필요한 위치.

§4.5 카테고리 효과

TFT2 카테고리에서 잔류율 0.725 관측. LoL(0.418)과 크게 다름. 같은 스트리머의 다른 카테고리에서 잔류율이 달라진 사례 — 인접 콘텐츠 다각화 간접 근거.

§4.6 성장 경로 3단계

P1(잔류율 개선) → P2(유튜브 전환 퍼널) → P3(유입 다각화). P4(팔로워 풀 확대)는 P1~P3의 결과.

관찰됨~추정 코호트 밴드 분포 관찰이지 인과 아님. 개별 채널 적용 검증 전.
PART II — §5: 재진단
§5 재진단
포지셔닝 업데이트 · YouTube 자산 진단 · 전략 프레임 Q 업데이트
YouTube 데이터 확보로 P2(유튜브 전환 퍼널)가 P3에서 승격. "3배" 목표를 7개 질문으로 구조화.

§5.1 포지셔닝 업데이트

4축 진단(§3) 이후 YouTube 데이터 추가 확보. 외부 도달 자산(Shorts 672개, 911만 조회수)이 확인되면서 진단 범위 확장.

§5.2 YouTube 자산 진단

Shorts 영상당 조회수 13,163 (일반 영상 2,845의 4.8배). 하이라이트 유형 영상당 30,144으로 도달 효율 최상위. 그러나 Shorts → Chzzk 전환 장치(description 링크)는 672개 중 6개(0.9%)에만 존재.

§5.3 우선순위 업데이트

P2(유튜브 전환 퍼널)를 기존 P3에서 승격. 이유: 실행 난이도 최저(description 템플릿 1개), 측정 가능, 성공 시 다른 장벽 해소의 동기 생성.

§5.4 전략 프레임 Q — 7개 질문

Q1(잔류율 개선 경로), Q2(마일스톤 정의), Q3(YouTube↔Chzzk 전환 구조), Q4(팔로워 풀 확대), Q5(콘텐츠 다각화), Q6(정체성 스케일링), Q7(수익화 타이밍). Q3에 대해 교차 시계열 분석(§7 §4)으로 부분 답변 확보.

§5.5 마일스톤 시뮬레이션

MS1(avg 120) → MS2(avg 200) → MS3(avg 350). 각 마일스톤별 필요 잔류율·방송시간·팔로워 조합을 시뮬레이션. 코호트 밴드 분포 기반 추정.

관찰됨 YouTube 데이터는 확인된 사실. 마일스톤 시뮬레이션은 추정.
PART III — §6: 목표 업데이트
§6 목표 업데이트
"3배"의 정의 · 효율 밸리 · 마일스톤 트레이드오프 · 경보 임계값
"평균 시청자 3배(69→207)"는 잔류율 개선 + 팔로워 확대의 동시 달성을 요구하며, 중간에 효율 하락 구간을 반드시 통과해야 한다.

§6.1 "3배" = avg 69 → 207

평균 시청자 3배가 목표의 정량적 정의. 단순 산술이 아니라 avg = follower × 전환율이므로, 팔로워 확대와 잔류율 유지를 동시에 달성해야 함.

§6.2 효율 밸리

팔로워 5K~15K 구간에서 효율(뷰어십/팔로워)이 하락하는 "밸리" 존재. 비활성 팔로워 비중 증가 때문. 이 구간을 통과하면서 전환율이 자연 희석되는 것은 정상이며, 핵심은 잔류율을 함께 올려서 avg를 유지하는 것.

§6.3 마일스톤별 트레이드오프

마일스톤avg 목표필요 잔류율필요 방송시간핵심 과제
MS11200.55~0.6580~100h방송시간 축소 + 잔류율 개선

§6.4 경보 임계값

효율 < 0.7, 잔류율 < 0.30, 전환율 < 1.0%, 유튜브 업로드 < 3건(2개월 연속) 시 실행 중단·원인 분석.

§6.5 수익 프레임

MS1~MS3 달성 경로에서의 수익 구조 변화를 프레이밍. 현 단계에서 수익화보다 체급 확대가 선행 과제.

추정 마일스톤 수치는 코호트 분포 기반 시뮬레이션. 실제 경로는 실행 결과 의존.

§11 트래킹 체계
측정 구조 · 전환 프록시 추적 · W24 타임라인
일별 스냅샷(KST 03:00-05:00) + 주간 리뷰 + 월간 경보 체크. W12 중간리뷰에서 3단계 착수 여부 결정.

§11.1 일별/주간/월간 측정

일별: 치지직 팔로워·세션 기록 + 유튜브 영상별 조회수·구독자(YouTube Data API v3). 주간: 잔류율·팔로워 순증·Shorts 업로드 수·조회수 합계. 월간: 효율·잔류율·전환율·업로드 빈도 경보 체크(§6.4 임계값).

§11.2 전환 프록시 추적

1단계 효과 측정 핵심. Shorts 업로드일 기준 전후 팔로워 변화 + 주간 전환 프록시 근사치 산출. 현재 0.0407%에서 0.05%+ → 전환 기여 판단, 0.1%+ → 유의미 개선.

§11.4 체크포인트

W4(적용률 확인) → W8(잔류율 방향) → W12 중간 리뷰(3단계 착수 조건 판단) → W24 종합 리뷰(MS1 진입 경로 평가, 전체 전략 재검토).

W12에서 잔류율 미개선(<0.43) 시 세션 분할 재설계, 뷰어십 하락(<9K) 시 방송 일수 증가로 보전, 둘 다 악화 시 2단계 롤백.

추정 타임라인은 최선 시나리오. 실행 지연·조건 미충족 시 일정 변동.

외부 데이터 고지: 치지직 데이터는 Softcon 기반(플랫폼 공식 API 아님). 유튜브 데이터는 YouTube Data API v3 공개 조회수 기반(YouTube Analytics 시청 지속시간·유입 경로·구독 전환 데이터 아님). 절대 수치보다 추세와 상대 위치 중심으로 해석.
