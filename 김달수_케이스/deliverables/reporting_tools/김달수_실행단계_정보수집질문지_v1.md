# 김달수 1만 목표 전략 — 정보 수집 질문지 (v1)

**용도:** 1만 팔로워 목표 전략 수립 · 실행 단계 진입(§10~§12)에 필요한 본인 입력 수집.
**작성:** 2026-06-01
**위상:** 분석 클로즈(§1~§9) 완료 후 *실행 클로즈로 가는 추가 입력*. 보고 직후·후속 응대 시 자연 흐름에 녹여서 수집.

---

## 도입부 — 사용 원칙

### 합의 영역 (방법론 v1 §0.5)

| 단계 | 영역 | 처리 |
|---|---|---|
| 1단계 | 분석에 명확히 필요 | 공유 권장 |
| 2단계 | 사업 지속성 (재정) | **본인 선택** — 위치만, 액수 아님 |
| 3단계 | 자발 노출 시에만 | 직접 캐지 않음 |
| 4단계 | 받지 않음 | 자발 언급해도 기록·외부 공유 안 함 |

→ 김달수는 친분 관계로 평서체 합의 영역. 정식 합의서 미발송. *민감 영역은 본인 자발 노출 한정.*

### 질문 사용 원칙

- **순차 진행 X.** 자연 대화 흐름에 *영역별 1~2개씩* 녹이기.
- **묵비권 보장.** 모든 질문 답하기 곤란하면 패스 OK.
- **본인 어휘 보존.** 답을 표준어로 옮기지 말기 (방법론 v1 §1.5).
- **한 번에 다 묻지 말기.** 보고 직후 일부, 1주 후 일부, 3개월 후 일부.

# Part A — 정체성·자기 인식 영역

> 분석 결과(§1·§5)의 정체성 가설과 본인 인식 정합 확인. *분석 클로즈에 박힌 정체성이 본인 명시 확인을 못 받은 상태.* 본인 검증 필요.

## A1. 채널 정체성 자기 정의

**질문:** "본인이 *지금 본인 채널이 어떤 채널*이라고 한 줄로 설명한다면?"

**응답 형식:** 자유 답 (1~3 문장)

**해석:** 분석 결과 "*롤로 사람 데려와서 사람에 정붙는 사촌동생 같은 채널*"과 *얼마나 정합*하는지. 격차 클수록 추가 인터뷰 필요.

## A2. 본인 채널의 강점 자기 인식

**질문:** "본인이 다른 비슷한 채널들과 *차이점*은 뭐라고 생각하세요?"

**응답 형식:** 자유 답

**해석:** 본인이 *진성도 상위 8%·1년 +227%* 같은 데이터 기반 강점을 *자기 어휘로 인지*하는지. 데이터 모르고도 같은 답이면 *기존 자기 인식 정렬*.

## A3. 자기 의심 영역

**질문:** "방송하다가 *자기 자신이 부족하다·이게 맞나* 의심 들 때 있으세요? 있다면 어떤 영역에서?"

**응답 형식:** 자유 답

**해석:**
- 자기 의심 *약함* (구비바 부록 E와 정합) → 기존 분석 유지
- 자기 의심 *강함* 발견 시 → 구비바 통합 진단 패턴 점검. 매력·실력·설정 우선순위 추가 질문 가능.

## A4. 영속 의향

**질문:** "본인 *방송 졸업 시점* 생각해두신 거 있으세요? 아니면 그냥 계속하실 생각?"

**응답 형식:** 자유 답

**해석:** 영속 의향형 케이스인지 결정. 영속 의향 강하면 §6.4 처리 적용 — 1만 목표가 *데드라인형*인지 *영속 통과점*인지 본인 답 받음.

## A5. 3년 뒤 채널 비전

**질문:** "3년 뒤에 본인 채널이 *어떤 모습*이면 성공한 거 같으세요? 팔로워 숫자 말고 어떤 모습으로."

**응답 형식:** 자유 답

**해석:** 정성적 비전. *닮고 싶은 채널 모델* 있는지 확인.

# Part B — 운영 자원·시간 영역

> §10 실행 설계의 *시간 자원 점검* 입력. 액션 분해 4단계에서 *본인 시간 부담 점검* 필수.

## B1. 시간 분배

**질문:** "하루에 방송 + 방송 준비 + 커뮤니티 관리 각각 *대략 얼마나* 쓰세요? 평균 감으로 OK."

**응답 형식:** 자유 답 (시간 수치)

**해석:** 외부 채널·실행 액션 추가 시 *여유 시간* 추정.

## B2. 방송 시간대 변천

**질문:** "방송 시간대가 1년 전이랑 지금이랑 *바뀐 게 있나요*? 있다면 왜?"

**응답 형식:** 자유 답

**해석:** 시간대 변천이 *본인 직업·라이프 변화*와 어떻게 정합. 외부 영향 요인 파악.

## B3. 본업·부업 영역

**질문:** "지금 *전업 스트리머*이신지, 다른 일도 같이 하시는지?"

**응답 형식:** 자유 답 (자발 한정)

**해석:** 영속 의향과 연결. 사이드잡 있으면 *시간 자원 제약* 명확. 합의 1-2 단계 — *자발 노출만*.

## B4. 콘텐츠 외주화 가능성

**질문:** "방송 외에 *편집·홍보·디자인* 같은 거 *외주 맡길 수 있는* 자원 있으세요? 아니면 본인이 다 하는 편?"

**응답 형식:** 자유 답

**해석:** 실행 액션 중 *외부 의존* 가능 영역 식별 (편집자 구인·기획 도움 등).

# Part C — 콘텐츠 영역

> §10 실행 액션 중 *콘텐츠 변경*은 본인이 *진심으로 좋아하는 영역*에서 발생해야 지속 가능.

## C1. 가장 좋아하는 자기 방송 장면

**질문:** "1년 동안 방송 중에 *가장 잘 했다·즐거웠다* 싶은 장면 있으세요?"

**응답 형식:** 자유 답

**해석:** 진성도 상위 8% 결과의 *근거 장면*. 잔류 동력(*사람에 정붙는 무대*) 직접 사례.

## C2. 다시 보기 부끄러운 장면

**질문:** "반대로 *다시 보기 부끄러운·후회되는* 장면 있으세요?"

**응답 형식:** 자유 답

**해석:** 본인의 *분리 보호 영역* 식별. 노방종 21일 영역인지 다른 영역인지 확인.

## C3. "나답다" 콘텐츠

**질문:** "본인이 *가장 본인답다*고 느끼는 콘텐츠는 뭐예요? 솔랭이 그래요, 다른 거예요?"

**응답 형식:** 자유 답

**해석:** 분석 결과 *솔랭의 사람 무대화*가 잔류 동력 핵심인데 본인도 같이 보는지.

## C4. "안 맞는다" 콘텐츠

**질문:** "반대로 *별로 안 맞는다·하고 싶지 않다* 싶은 콘텐츠는요?"

**응답 형식:** 자유 답

**해석:** 콘텐츠 확장 방향 결정 시 *제외 영역*. 본인 기질 점검.

## C5. 방송 외 취미·관심사

**질문:** "방송 외에 본인이 *진심으로 좋아하는 거* 있으세요? 음악·책·게임·영화 같은 거."

**응답 형식:** 자유 답

**해석:** 콘텐츠 확장 재료 후보. 본인의 *방송 외 자기*가 분리 보호 영역인지 활용 가능 영역인지.

# Part E — 시청자 관계 영역

> §5·§6의 진성도·참여 밀도 데이터의 *정성적 보강*. 본인이 시청자를 어떻게 인지하는지.

## E1. 단골 수·호칭

**질문:** "본인이 *단골 시청자*라고 부르는 사람들 *몇 명* 정도 있어요? 그분들이 본인을 *뭐라고* 부르세요?"

**응답 형식:** 자유 답

**해석:** 진성도 상위 8% 결과의 *얼굴 있는 단골* 확인. 내부 문화 자산 파악.

## E2. 내부 밈·문화

**질문:** "방송 안에서 *단골끼리만 통하는 농담·표현·문화* 같은 게 있나요? 있다면 어떤 거?"

**응답 형식:** 자유 답

**해석:** 잔류 동력의 *콘텐츠화된 자산* 식별.

## E3. 시청자 칭찬 vs 놀림 비율

**질문:** "시청자분들이 본인한테 *칭찬·놀림·비판* 어느 게 더 많이 와요?"

**응답 형식:** 자유 답

**해석:** 본인이 시청자 반응을 *어떻게 해석*하는지. 칭찬 위주면 자기 평가 *정렬* 가능성, 놀림 위주를 *부정 인지*하면 자기 의심 영역.

## E4. 부정적 반응 처리

**질문:** "시청자가 *기분 안 좋게* 받아쳤을 때 본인이 어떻게 처리하세요?"

**응답 형식:** 자유 답

**해석:** 본인의 *멘탈 처리 방식*. 자가 회복 메커니즘 있는지 (구비바 케이스 학습 패턴).

## E5. 보고 싶은 시청자 vs 실제

**질문:** "시청자가 본인을 *어떻게 봐줬으면 좋겠다* 하는 모습이 있고, *실제로 어떻게 보고 있는 것 같은지*. 둘이 같아요, 달라요?"

**응답 형식:** 자유 답

**해석:** 의도-수용 정합 점검 (구비바 케이스 C6 학습). 격차 크면 정체성 재검토.

## F3. 부담 한계선

## F5. 외부 피드백 경험

**질문:** "방송에 대해서 *남이 조언·평가·훈수* 해줬을 때 어떠셨어요?"

# Part G — 컨설팅 기대 영역

> 본인이 *우리 분석·실행 지원에 무엇을 원하는지* 명시 확인. §10·§12 설계 입력.

## G2. 실행 단계 함께할 의향

**질문:** "1만 목표 가는 과정에서 *우리가 어디까지 같이* 가면 좋을 것 같으세요? *6개월·1년 같이*? *분석만*? *필요할 때 부르기*?"

**응답 형식:** 자유 답

**해석:** §12 후속 응대 형식 결정. 본인 의지에 따라 트래킹·재진단 주기 조정.

## G3. 후속 응대 형식 선호

**응답 형식:** 다중 선택
- A. 화면공유 (오늘 형식)
- B. 문서 직접 읽기
- C. 짧은 음성 정리
- D. 디스코드 채팅 즉답
- E. 다른 방식

**해석:** §11·§12 소통 주기·형식 결정.

# Part H — 1만 목표·재정 영역

> §6 트레이드오프의 본인 답 받기. 영속 의향형 케이스 처리(§6.4) 적용.

## H1. 1만 목표 시기
