# needmorefal × 소프트콘 뷰어십 — 데이터 제휴 제안서

**needmorefal · 2026. 6.**

---

## 1. 시장 배경

방송 지표와 데이터를 **표시**하는 서비스는 이미 여럿 있습니다. 소프트콘 뷰어십을 포함해, 스트리머가 자기 숫자를 볼 수 있는 환경은 갖춰져 있습니다. 그런데 정작 그 데이터를 **읽고 해석해주고, 성장 방향을 제시**해주는 서비스는 없습니다. 숫자는 있는데 읽는 사람이 없는 구조입니다.

needmorefal은 그 빈자리에 들어가는 서비스입니다.

## 2. needmorefal은 어떤 서비스인가요

스트리머 채널의 방송 데이터와 동급 비교군을 분석해서, **비공개 성장 진단 리포트**를 만드는 서비스입니다.

치지직 공개 API, YouTube Data API v3, 스트리머 본인 채널 통계, 여러 뷰어십 데이터 등 **복수의 데이터 소스를 교차 수집**하고, 동급 채널 100~500여 개와 비교해서 객관적 위치를 진단하고, 다음 체급까지의 경로를 수치로 설계합니다.

현재 1인 개발 및 운영 중입니다.

## 3. 왜 제휴를 제안하는가

needmorefal은 이미 치지직 공개 API와 YouTube Data API v3로 상당 부분의 데이터를 자체 수집하고 있습니다. 제휴를 제안하는 이유는 양쪽 모두에게 이점이 있기 때문입니다.

### needmorefal 시점 — 효율, 신뢰성, 초기 트래픽

소프트콘이 이미 정제해둔 SOOP·치지직·트위치·유튜브 4개 플랫폼의 시계열 데이터를 활용하면, 수집 시간을 줄이고 해석에 집중할 수 있습니다. 동시에, 컨설팅 리포트는 데이터 출처의 신뢰성이 곧 리포트의 신뢰성입니다. 소프트콘 뷰어십은 3년간의 운영을 통해 스트리밍 데이터 시장에서 신뢰성 있는 출처로 자리잡았고, 이 신뢰가 needmorefal 리포트의 근거 품질을 높입니다.

솔직한 부분도 말씀드리면, needmorefal은 사이트 개발이 완료되더라도 초기 트래픽이 약합니다. 서비스를 알릴 수 있는 노출 경로가 필요하고, 소프트콘 뷰어십이 그 역할을 해줄 수 있다면 초기 성장에 큰 도움이 됩니다. 그리고 이 트래픽은 일방적으로 받기만 하는 구조가 아닙니다 — needmorefal이 성장할수록 아래에서 설명하는 시장 교육 효과가 소프트콘으로 돌아갑니다.

### 소프트콘 시점 — 시장 교육과 고객층 확장

지금 대부분의 스트리머는 데이터를 보지 않습니다. needmorefal이 컨설팅을 통해 "데이터를 읽는 법"을 알려줄수록, 데이터의 가치를 체감하는 스트리머가 늘어납니다. 이 사람들은 컨설팅이 끝난 뒤에도 스스로 숫자를 확인하고 해석하려는 습관이 남고, 소프트콘 뷰어십의 잠재적·장기적 구독 사용자가 됩니다.

여기서 한 단계 더 나아갈 수 있습니다. needmorefal이 간단한 데이터 해석 방법론을 일반에 공개하면, **일반 시청자**도 자기가 즐겨보는 스트리머의 지표에 관심을 갖게 됩니다. 소프트콘의 고객층은 현재 데이터 리터러시에 관심이 있는 스트리머나 MCN에 한정되어 있지만, 일반 시청자까지 확장되면 시장 자체가 달라집니다. 야구 세이버메트릭스가 처음에는 팀 프런트 오피스 전용이었지만, 팬들이 WAR·OPS 같은 지표를 이해하기 시작하면서 야구 통계 사이트의 트래픽이 폭발한 것과 같은 구조입니다.

needmorefal이 커질수록 소프트콘의 시장도 같이 커집니다.

## 4. 서로 하는 일이 다릅니다

명확히 해둘 부분입니다.

- **원자료 재판매가 아닙니다.** 소프트콘 데이터를 그대로 외부에 제공하지 않습니다.
- **랭킹·대시보드 서비스가 아닙니다.** 소프트콘 뷰어십과 경쟁하지 않습니다.
- **개별 스트리머 대상 비공개 컨설팅 리포트의 근거 데이터 중 하나**로 사용합니다.

소프트콘이 "데이터를 보여주는" 서비스라면, needmorefal은 "데이터를 읽어주는" 서비스입니다. 시장이 겹치지 않고, 오히려 소프트콘 데이터가 다양한 방식으로 활용되는 사례가 되는 구조입니다.

## 5. 리포트에서 소프트콘 데이터가 쓰이는 방식

| 필요 데이터 | 리포트에서의 용도 |
|---|---|
| 채널별 시청자 추이 (평균/최고) | 성장 궤적 산출, 동급 비교군 내 상대 위치 판정 |
| 방송 시간 데이터 | 잔류율 산출, 방송시간-시청자 관계 분석 |
| 카테고리 분류 | 카테고리 내 순위 산출, 발견 가능성 진단 |
| 팔로워 수 추이 | 팔로워 대비 시청 전환율 계산 |
| 채팅 활성도 | 시청자 참여도·커뮤니티 밀도 분석 |

이 데이터는 치지직 API와 YouTube API에서도 부분적으로 수집 가능하지만, 소프트콘의 크로스 플랫폼 시계열이 코호트 설계 정밀도를 높이는 데 기여합니다.

## 6. 참고: 멜로밍 제휴 사례와의 차이

소프트콘은 최근 멜로밍과 전략 제휴를 진행하신 것으로 알고 있습니다 (PRO 멤버십 구독자에 PLUS 혜택 제공). 멜로밍 제휴가 "소프트콘 서비스를 더 많은 사용자에게 노출"하는 구조라면, needmorefal 제휴는 "소프트콘 데이터 위에 해석 레이어를 얹어 새로운 활용 사례를 만드는" 구조입니다.

방향이 다르기 때문에 기존 제휴와 충돌하지 않습니다.

## 7. 진단 사례 (요약)

### 사례 1 — 치지직 게임 스트리머 (팔로워 약 6,000명, 활동 3년 차)

- **의뢰 시점:** "열심히 하는데 정체된 것 같다."
- **진단 결과:** "정체"가 아니라 숫자를 읽는 틀이 없었음. 최고 시청자 1년간 +227% 성장. 동급 131명 비교에서 팔로워 대비 시청 효율 상위 10위권.
- **동시에 발견된 문제:** 잔류율 동급 중앙의 65%, LoL 카테고리 100위 밖.
- **설계한 것:** 1만 팔로워 목표를 매달 점검 가능한 수치 경로로 전환. 세 레버의 순서와 멈추는 조건.
- **의뢰인 반응:** "평소에 나를 돌아보며 나에게 당연히 했어야 했던 질문들이 있었지만 실제로는 그러지 못했다는걸 인식하는 계기가 됐고, 이번 기회에 깔끔하게 모아서 들을 수 있어서 너무 감사했다. 그리고 앞으로의 성장전략까지 꼼꼼히 코칭해주셔서 안심이 된다."

### 사례 2 — 치지직 종합게임+버추얼 채널 (팔로워 약 730명, 활동 2년 차)

- **의뢰 시점:** "성장이 더딘 것 같다."
- **진단 결과:** 코호트 323채널 + VTuber 576채널 전수 분석. 방송 내 잔류율 상위 14%, 전환율·효율 동체급 상위 — "작지만 단단한 엔진". 반면 월 112시간(코호트 최상위) 방송량과 시청자 사이 양의 상관 없음(r = −0.315).
- **동시에 발견된 문제:** 피크-일상 리텐션 27%(동체급 하위 25%). 최고 방송과 일상 방송의 격차가 성장 병목.
- **설계한 것:** 582건 방송 데이터 OLS 회귀 분석으로 통제 가능한 레버 분리. "더 많이 방송하는 것"이 아니라 "같은 방송에서 더 많은 가치를 뽑는 것"으로 방향 전환. 3단계 로드맵 설계.
- **의뢰인 반응:** "성장 방향에 대해서 감으로만, 경험으로만 알아보고 있었는데 확실히 잘되는 분들 데이터를 같이 모아놓고 보니까 너무 명확하게 보여서 깜짝 놀랐다. 또 막연하게 해야지 해야지 하고 생각만 하고 계속 미루고 있던 것들이 많았는데 외부의 시선으로 따끔하게 알려주시니까 두루뭉실한 고민이나 생각들이 체계적인 실행단계로 옮겨져서 좀 더 방송에 집중할 수 있게되어 너무 고맙게 생각한다."

이 리포트들이 치지직 공개 API, YouTube Data API v3, 스트리머 본인 통계를 기반으로 만들어졌으며, 소프트콘 뷰어십 데이터가 코호트 설계와 크로스 플랫폼 비교에 활용되었습니다.
