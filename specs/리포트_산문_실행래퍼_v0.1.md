# 리포트 산문 실행 래퍼 v0.1

> **지위**: `리포트_산문_시스템_v0.2.md`(규칙 원본)을 LLM이 산출물 생성·수정·검수 시 실행하기 위한 래퍼.
> **관계**: 본 문서는 규칙을 복제하지 않고 참조한다. 규칙 충돌 시 원본(v0.2)이 우선.
> **버전**: v0.1 (2026-06-17). 산문 시스템 v0.2에 대응.

---

## 1. 입력 슬롯

산출물 생성·수정 전 아래 슬롯을 확인한다. 미지정 항목은 기본값을 적용하되, 기본값 적용 사실을 출력 시 명시한다.

| 슬롯 | 설명 | 기본값 |
|---|---|---|
| `문서유형` | 장르 (§5 레지스트리 참조) | 진단 보고서 (검토용 요약) |
| `대상독자` | 30초 / 10분 / 정밀 중 주 독자 | 10분 독자 |
| `원문` | 렌더링할 MASTER 원문 또는 분석 결과 | (필수 — 없으면 중단) |
| `출력형태` | md / html / pdf / docx | md |
| `외부확인가능여부` | 원자료 접근 가능 여부 → §4 검증 주체 표현에 영향 | 불가 |
| `유지할_전문성` | 독자가 이해하는 도메인 전문 용어 목록 (비워두면 §2 해상도 규칙 기본 적용) | (빈 목록) |
| `금지사항` | 이 문서에서 사용 금지인 용어·표현 | (빈 목록) |

## 2. 실행 순서

아래 순서대로 처리한다. 각 단계는 해당 §을 참조하여 판단한다.

| 순서 | 단계 | 참조 | 확인 사항 |
|---|---|---|---|
| 1 | **범위 확인** | §0 지위·범위 | 문서유형이 적용 범위 내인가? 범위 밖이면 중단하고 알린다. |
| 2 | **장르 확인** | §5 레지스트리 | 해당 장르의 상태값은? 사례 확인 장르면 기존 패턴 따름, 예약 장르면 규칙 추출 모드. |
| 3 | **독자 해상도 설정** | §2 수신자 축 | 대상독자 슬롯에 따라 해상도 규칙 적용 수준 결정. 전문성 보존 규칙 확인. |
| 4 | **문체 층 배정** | §1 문체 3층 | 기능 단위별 문체 배정. 본문=다체, 표/수치=음슴체, 커버노트/고지=합니다체. |
| 5 | **정직성 등급 부여** | §4 정직성 조항 | 각 주장·권고에 단정 어휘 등급(확실/거의 확실/관찰됨/추정) 배정. 검증 주체 표현 점검. |
| 6 | **구조 적용** | §3 구조 패턴 | 결론 카드, 리드→전개, 한계 섹션, 권고 우선순위화, 용어 단일화. |
| 7 | **검수** | 아래 체크리스트 | 전 항목 통과 확인. |

## 3. 충돌 우선순위

규칙 간 충돌 시 위가 아래를 이긴다:

1. **정직성** (§4) — 등급을 낮추거나 한계를 숨기는 방향의 편집은 어떤 이유로도 불가.
2. **전문성 보존** (§2 보존 규칙) — 핵심 수치 원단위·비교기준·데이터출처·한계·강건성·원문위치는 삭제 불가.
3. **독자 해상도** (§2) — 전문 용어 제거, 정밀도 다운그레이드 등. 단 보존 규칙 항목에는 적용 안 함.
4. **문체 규칙** (§1) — 기능 단위별 문체 통일.
5. **형식 간결화** (§3 표 수 제한 등) — 가장 낮은 우선순위. 증거 밀도가 필요하면 양보.

예시: "표를 4개 이하로 줄여라" vs "핵심 결론의 근거 표를 유지하라" → 근거 표 유지(우선순위 2 > 5).

## 4. 검수 체크리스트

산출물 완성 후 아래를 순서대로 확인한다. 불합격 항목이 있으면 수정 후 재검수.

### 4.1 문체 검수
- [ ] 본문 서술: 다체로 통일되었는가?
- [ ] 표·수치 불릿·한계 목록: 음슴체·명사형인가?
- [ ] 커버노트·고지·연락처: 합니다체인가?
- [ ] 같은 기능 단위 안에서 문체가 섞이지 않았는가?

### 4.2 구조 검수
- [ ] 결론 카드가 2개 이하인가?
- [ ] 모든 섹션이 리드(한 줄 요약) → 전개 구조인가?
- [ ] 한계 섹션이 존재하며 번호 목록·음슴체인가?
- [ ] 권고가 효과 큰 순서로 정렬되고 근거 역참조가 있는가?

### 4.3 정직성 검수
- [ ] 모든 주장에 단정 어휘 등급이 적절한가? (등급 건너뛰기 없음)
- [ ] 검증 전 권고에 "초기 관찰 기반" 단서가 붙었는가?
- [ ] "독립 검증" 표현이 없는가? (실제 외부 주체 없으면 금지)
- [ ] "복수 AI 모델 교차검토"에 "해석 일관성 점검" 한정 문구가 있는가?
- [ ] 외부 데이터에 출처 고지 + "추세·상대 위치 중심" 해석 지침이 있는가?

### 4.4 보존 검수
- [ ] 핵심 수치의 원 단위가 살아 있는가?
- [ ] 비교 기준이 명시되어 있는가?
- [ ] 데이터 출처가 기재되어 있는가?
- [ ] 방법론상 한계가 기재되어 있는가?
- [ ] 강건성 여부 언급이 있는가? (해당 시)
- [ ] 원문/근거 섹션 위치 참조가 있는가?

### 4.5 용어 검수
- [ ] 문서 내 동의어가 없는가? (grep 검증)
- [ ] `금지사항` 슬롯의 용어가 사용되지 않았는가?
- [ ] `유지할_전문성` 슬롯의 용어가 보존되었는가?

## 5. 출력 형식

검수 통과 후, 산출물과 함께 아래 메타를 기록한다:

```
[산문 래퍼 실행 기록]
- 문서유형: {문서유형}
- 대상독자: {대상독자}
- 장르 상태: {§5 상태값}
- 적용 산문 시스템: v0.2
- 기본값 적용 항목: {기본값을 쓴 슬롯 목록}
- 검수 불합격→수정 항목: {있으면 기술, 없으면 "없음"}
```
