### A-3. GPT Phase 3A

**세션 조건**: 별도 ChatGPT thread, 프로젝트 컨텍스트 미공유, 요식업 미언급

**Fact 기반**: ~80개 (독자 수집)
**분석 프레임**: 6-axis (사용자 행동, 수익모델, 데이터 접근성, 네트워크 효과, 규제·정책, 기술 제약)

**핵심 발견**:
- 스트리밍 ≠ "디지털 방송". Hybrid: 소셜 추천 + 게임형 retention + 팬 직접결제 + 실시간 상거래
- 최강 2개: 소셜 미디어 + 모바일 게임 (핵심 동형)
- 모바일 게임의 "고래 이용자 의존형 설계"가 후원경제와 구조적으로 동형
- Pareto α: YouTube 1.80, Instagram 1.84, Twitch 1.93 — rich-get-richer
- 자기제한 4가지: 행동 희소성, 전파 둔화, 상위 집중, 정책적 상한
- 전통방송(NAICS 5151)은 L1에서만 대응, L2 이상에서 "일방향 방송"이 결정적 Gap

**축 매핑 (본 프로젝트 5-axis로 변환)**:
| GPT 6-axis | 본 프로젝트 5-axis | 주요 발견 |
|---|---|---|
| 사용자 행동 | Activity | 모바일 게임: 세션 주기·보상 루프 대응 |
| 수익모델 | Resource | 모바일 게임: F2P+IAP 고래 구조 |
| 데이터 접근성 | (Constraint 일부) | 소셜 미디어: 알고리즘 발견가능성 |
| 네트워크 효과 | Feedback | Pareto α rich-get-richer |
| 규제·정책 | Constraint | 정책적 상한 |
| 기술 제약 | (Actor 일부) | 플랫폼 인프라 의존 |

- 기능별 분할 전략: 발견=숏폼소셜, 전환=라이브커머스, 유지=멤버십, 공급확장=UGC게임, 의례화=라이브이벤트
- 4가지 자기제한 메커니즘:

  2. 지갑점유율 상한 — 개인 가처분소득 중 후원 지출의 물리적 한계
  3. 통행세/정책 외생성 — 플랫폼 수수료·규제가 성장을 외부에서 제한
  4. 신뢰·안전 비용 내재화 — 유해 콘텐츠 관리 비용이 성장에 비례하여 증가
- 5대 구조적 리스크: whale concentration, regulatory design, trust & safety cost inflation, platform toll, creator labor burnout
- 한국 라이브 스트리밍 수명주기 판정: 재형성-초기 집중화 단계 (성숙기 초입)

**본 프로젝트와의 수렴점**:
- "창작자 멤버십·후원"은 Claude 3B의 메가처치(patronage logic)와 부분 수렴
- "whale concentration"은 GPT 3A의 모바일 게임 고래와 직접 수렴
- "지갑점유율 상한"은 메가처치의 자기제한(기부금 감소)과 수렴
- "creator labor burnout"은 #174(재정 리스크 스트리머 전가)와 수렴

## 부록 D. 용어 정의

| 용어 | 정의 |
|---|---|
| **SMT** | Structure Mapping Theory. Dedre Gentner의 유비 추론 이론. 표면→관계→체계의 3단계로 유비의 깊이를 평가. |
| **L1 / L2 / L3** | SMT의 3단계. L1=표면 속성, L2=관계 구조, L3=체계성/인과 사슬. |
| **5-Axis** | Actor, Resource, Activity, Constraint, Feedback의 5개 분석 축. |
| **복합 모델** | Frankenstein Model. 축별 최강 산업에서 해당 축의 프레임워크를 수입하는 방식. |
| **보조 렌즈** | Auxiliary Lens. 축별 최강이 아닌 산업이 횡단 주제에서 기여하는 역할. |
| **내부 재화** | 플랫폼 내에서만 통용되는 가상 재화. 원화→별풍선/치즈→환전의 폐쇄형 순환. |
| **고래(Whale)** | 소수의 고액 지출자. F2P 게임과 후원경제에서 매출의 대부분을 점유하는 이용자. |
| **파라소셜 관계** | 미디어 수용자가 퍼포머에 대해 형성하는 일방적 친밀감. 후원 동기의 핵심 매개 변수. |
| **후원 피로** | Donation fatigue. 반복적 후원 요청에 대한 심리적 피로로 기여금이 감소하는 현상. |
| **NAICS** | North American Industry Classification System. 산업 분류 체계. |
| **Pareto α** | 멱법칙 분포의 지수. α가 높을수록 상위 집중도가 높음(tail이 두터움). |
| **PFOF** | Payment for Order Flow. 증권사가 주문을 시장조성자에게 넘기고 수수료를 받는 모델. |
| **엑셀방송** | 스트리머에게 다량의 후원(별풍선)을 보내는 형태의 방송. 상위 수익 집중의 핵심 콘텐츠 유형. |
| **Cross-cutting concern** | 횡단 관심사. 특정 축에 귀속되지 않고 여러 축을 관통하는 구조적 주제. |
| **Connection / Gap / Caution** | SMT 판정의 3분류. Connection=대응 성립, Gap=대응 불성립 또는 자료 부재, Caution=대응은 있으나 오독 위험. |
| **Patronage logic** | 후원자-수혜자 관계에 기반한 자발적 금전 이전의 논리. 메가처치·스트리밍 공통. |
