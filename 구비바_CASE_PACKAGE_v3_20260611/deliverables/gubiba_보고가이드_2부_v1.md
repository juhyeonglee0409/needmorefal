## M1 — 방송 효과 심화 (15분)

> 리포트 §8-b(XGPS 교차검증 종합) + §8 종합 실행 로드맵 Phase 1 화면

**이 파트의 역할:** 1부에서 "방송 더 해도 안 된다"고 했는데, 그게 구비바만의 문제인지 검증한 결과를 보여줌.

### 교차검증 구조

**[전문]**
상위 채널 19개(avg 618~2,343)와 동체급 23개(avg 31~112)의 방송기록 4,000건을 추가 수집하여, 구비바 582건과 비교했다. 체급 차이를 빼기 위해 각 채널의 자기 평균 대비 상대성과(z-score)로 정규화.

**[쉽게]**
"1부에서 '방송 더 해도 안 된다'고 했잖아요. 이게 구비바만 그런 건지 알아보려고, 큰 채널 19개, 비슷한 채널 23개 방송기록을 추가로 모았어요. 총 42채널, 4,000건이에요."


### 한계수익 소진

**[전문]**
방송길이-시청자 상관: 동체급(LC) r=0.25 — 긴 방송이 시청자를 끌어옴. 상위(LA)와 구비바 r≈0 — 무상관. 구비바가 상위채널과 같은 패턴. 해석: 월 102.9h에서 이미 한계수익을 소진. "더 길게 해도 효과 없다"가 구비바 고유가 아니라 상위채널도 같은 패턴.

**[쉽게]**
"비슷한 채널에서는 긴 방송이 시청자를 끌어와요. 근데 큰 채널에서는 효과가 없어요. 구비바도 효과가 없어요."

"이건 좋은 소식이에요. '문제가 있어서 안 느는 게 아니라, 이미 그 단계를 넘어선 거'예요. 큰 채널들도 방송 길이로 시청자를 못 끌어와요."

**[체크인]** "여기까지 납득돼요?"


### 잔류율 감소는 보편적

**[전문]**
잔류율×방송길이: 모든 체급에서 r=-0.24~-0.37(긴 방송일수록 잔류율 감소). 구비바의 감소가 가장 완만 — 방송이 길어져도 시청자가 상대적으로 덜 빠짐.

**[쉽게]**
"긴 방송하면 잔류율이 떨어지는 건 모든 채널 공통이에요. 근데 구비바는 그 떨어짐이 제일 작아요. 긴 방송에서도 시청자가 잘 버틴다는 뜻이에요."

## M2 — 카테고리·시간대 (10분)

> 리포트 §8-b 발견 1, 4 화면

### talk > game 역전

**[전문]**
상위 19채널, 동체급 23채널 모두 game > talk. 구비바만 talk > game 역전. 시청자가 게임이 아니라 스트리머 자체에 반응.

**[쉽게]**
"다른 채널들은 전부 게임 방송이 잡담보다 시청자가 많아요. 구비바만 잡담이 더 높아요."

"이건 중요한 발견이에요. 시청자가 '뭘 하는지'가 아니라 '누구인지'를 보러 오는 거예요. 게임은 미끼고, 구비바 자체가 콘텐츠인 거예요."

**(질문 대비) "그럼 talk만 하라는 거예요?"**
→ "아니에요. talk이 높다는 건, 어떤 게임을 하든 본인의 화법·반응이 핵심이라는 뜻이에요. 소울라이크+본인 화법이 최고 성과인 것도 같은 구조예요."


### 저녁 역전

**[전문]**
동체급에서 저녁(18-21시)은 프라임타임(peak_z +0.33). 구비바만 저녁이 최저. 시간대 자체의 문제가 아니라 구비바 고유 요인.

**[쉽게]**
"비슷한 채널에서 저녁은 가장 좋은 시간대예요. 근데 구비바만 저녁이 제일 약해요. 왜인지는 아직 모르지만, 현재 오후 편성이 잘 맞는 거예요."

**[체크인]** "본인이 느끼기에도 talk이 반응 좋아요?"

## M4 — 리텐션 과제 (15분)

> 리포트 §3(현재 위치 진단) + §5/§6 576코호트 진단 화면

### 잔류율 vs 리텐션 구분

**[전문]**
잔류율(방송 내, avg/peak) = 0.712, 상위 14%. 리텐션(방송 간, peak_p50/peak_max) = 26.9%, 하위 25%. 방송 "안에서는" 시청자가 잘 남지만, "다음 방송에" 다시 오는 비율이 낮다.

**[쉽게]**
"여기서 두 개를 구분해야 해요."
- 잔류율: "방송 켜면 들어온 사람이 잘 안 나가요. 상위 14%. 이건 확정 강점."
- 리텐션: "근데 다음 방송에 다시 오는 비율이 하위 25%예요. 한 번 왔다가 다음엔 안 오는 거예요."

"두 개가 동시에 있다는 게 핵심이에요. '한 번 오면 잘 잡는데, 다시 오게 하는 힘이 약하다.' 그래서 팔로워가 안 느는 거예요."


### P0 = 리텐션 개선

**[전문]**
576채널 3-layer 분석 결과, 리텐션이 성장의 최대 병목. P0(최우선) = 리텐션 개선, P1 = 팔로워 1,500 변곡점.

**[쉽게]**
"우선순위를 잡으면요."
- "1순위: 리텐션 올리기. 다음 방송에 다시 오게 만드는 것."
- "2순위: 팔로워 1,500 변곡점 넘기기."
- "3순위: 유튜브 재시작. 근데 이건 1순위 해결 후."

"리텐션이 올라가면 팔로워도 자연히 올라가는 구조예요."

**[체크인]** "이 두 가지 우선순위, 납득돼요?"

## M3 — 유튜브 판단 (10분)

> 리포트 §7 유튜브 타당성 화면

### 유튜브는 필요하지만 지금은 아니다

**[전문]**
상위밴드 84채널 중 92.9% 유튜브 보유, 활성 73.8%. YT↔치지직 성장 상관 r≈0 — 가지고 있지만 성장 원인은 아님. 구비바 YT(166 subs, 휴면)는 하위 9.3%.

**[쉽게]**
"큰 채널 84개 중 93%가 유튜브를 가지고 있어요. 거의 다. 근데 유튜브 때문에 커진 건 아니에요. '커진 채널이 유튜브도 하는' 구조예요."

"구비바 유튜브는 166구독에 휴면 상태. 하위 9%예요."


### full_vod 폐기, clip 전환

**[전문]**
구비바 유튜브의 full_vod(치지직 아카이브 → YT) 잔류율이 모든 콘텐츠 중 최하위. clip/highlight로 전환해야 유의미.

**[쉽게]**
"지금 유튜브에 올리는 풀 VOD는 효과가 거의 없어요. 잔류율이 제일 낮아요. 긴 다시보기를 유튜브에서 보는 사람이 거의 없다는 뜻이에요."

"재시작한다면, 하이라이트나 클립으로 전환해야 해요. 그리고 이건 리텐션 개선(1순위) 이후에 하는 게 맞아요."

## M6 — 통합진단 ★ (20분)

> **토론 배틀 보조 문서를 별도 창에 띄우기.** 리포트는 일단 접기.

**⚠️ 이 파트가 전체 2부에서 가장 중요하고 감정적으로 무겁다.**

### 진입 프레이밍

"여기까지 데이터를 봤어요. 이제 좀 다른 얘기를 해볼게요. 데이터보다는 '인식'에 대한 이야기예요."

**[전문]**
세 가지 현상 — 매력 의심, 도네 자기검열, "전업 같은 취미" 자기정의 — 이 별개가 아니라 같은 뿌리에서 나온다고 보인다.

**[쉽게]**
"분석하면서 세 가지가 눈에 띄었어요."
1. "본인이 '매력이 부족하다'고 느끼는 것"
2. "후원 요청을 스스로 억제하는 것"
3. "'전업 같은 취미'라고 정의하는 것"

"이 세 가지가 따로따로가 아니라 같은 곳에서 나오는 것 같아요."

*(여기서 토론 배틀 보조 문서의 근거 5개를 순서대로 제시)*

4. **월 103시간** → "취미라고 부르기엔 투입량이 전업 수준이에요."
5. **3층 정체성 일치** → "코호트에서 드문 수준의 정체성 일치예요."

"이 데이터를 보면, '매력이 부족하다'는 자기 평가가 데이터와 맞지 않아요."

## 예상 질문 대비


### 교차검증 관련

**"42채널이면 적지 않아요?"**
→ [전문] Layer A 19ch, Layer C 23ch. 개별 채널의 방송기록이 각 50~120건이라 총 3,900건. 통계적 검정력은 건수로 결정됨. 채널 수가 적어 채널 수준 일반화에 한계는 있으나, 방송 수준 패턴은 충분.
→ [쉽게] 채널 수는 42개지만 방송 기록은 4,000건이에요. 패턴을 보기엔 충분해요.

**"한계수익 소진이면 방송 줄여야 하는 거 아니에요?"**
→ [전문] 1부와 동일 — "줄이면 올라간다"는 인과는 없음. "더 늘려도 안 올라간다"가 정확. 현행 유지는 본인 판단.
→ [쉽게] 줄이라는 게 아니에요. "더 늘려도 효과 없다"는 거예요.


### 리텐션 관련

**"리텐션 올리려면 뭘 해요?"**
→ [전문] §10 실행 설계에서 구체화. 가설: 예고(다음 방송 기대감 생성), 시리즈 구조(이어보기 동기), 정기 스케줄(습관 형성). 상위 궤적매칭 채널 사례 참고.
→ [쉽게] 다음 단계(§10)에서 구체적으로 잡아요. 큰 방향은 '다음에 또 와야 할 이유 만들기'예요.

**"리텐션 하위 25%면 심각한 거 아니에요?"**
→ [전문] 심각이 아니라 최대 레버. 잔류율 상위 14%는 "오면 잘 잡는다"의 증거. 리텐션이 낮다는 것은 "잡을 능력은 있는데 다시 오게 하는 구조가 없다"는 뜻. 구조를 만들면 가장 빠르게 개선 가능한 지표.
→ [쉽게] 심각하다기보다, 가장 큰 기회예요. 오면 잘 잡으니까, 다시 오게만 하면 바로 효과가 나요.


### 유튜브 관련

**"유튜브 안 해도 되는 거예요?"**
→ [전문] 안 해도 되는 게 아니라, 지금은 아니다. 상위 92.9%가 보유. 다만 YT↔성장 r≈0이므로, 치지직 리텐션을 먼저 잡고 착수하는 게 효율적.
→ [쉽게] 나중엔 해야 해요. 큰 채널 93%가 가지고 있으니까. 근데 지금 유튜브에 시간 쓰는 것보다 리텐션 올리는 게 먼저예요.


### 통합진단(M6) 관련

**"심리 분석을 하는 거예요?"**
→ [전문] 심리 분석이 아니라 패턴 분석이다. 세 가지 현상(매력 의심, 도네 검열, 자기정의 격차)이 데이터에서 관찰되고, 이것들이 같은 구조를 공유한다는 해석. 맞는지는 본인만 판단 가능.
→ [쉽게] 심리 분석이 아니에요. 데이터에서 보이는 패턴이에요. 맞는지 아닌지는 본인이 판단하는 거예요.

**"이걸 왜 말하는 거예요? (불편함 표현)"**
→ "불편하면 여기서 멈춰도 돼요. 이걸 말씀드리는 이유는, 이 인식이 성장 전략에 영향을 주기 때문이에요. 도네 태도나 자기정의가 바뀌면 선택지가 늘어나요. 하지만 바꿔야 한다는 게 아니라, 인식하면 좋겠다는 거예요."
