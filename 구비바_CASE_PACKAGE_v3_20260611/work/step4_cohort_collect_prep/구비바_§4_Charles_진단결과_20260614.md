## 6. 권장 실행 경로 (Chrome 탐색 후 갱신)

### 경로 A (갱신): 소프트콘 단독 파이프라인 (**권장**)

```
Phase 1 — 모집단 수집 (랭킹 페이지):
1. 소프트콘 랭킹 4페이지 수집 (400채널 뷰어십 메트릭)
   URL: /ranking/softcone?platform=naverchzzk&page=1~4
2. 버추얼 랭킹 4페이지 수집 (400채널 T2 보조 코호트)
   URL: /ranking/virtualsoftcone?platform=naverchzzk&page=1~4

Phase 2 — 카테고리 판정 + 팔로워 (개별 상세 페이지):
3. Phase 1의 채널 중 peak_viewers가 구비바 band 범위(raw max 74~296)에
   해당하는 채널만 상세 페이지 방문
   URL: /channel/naverchzzk/{channel_id}
   수집: 카테고리별 뷰어십 비율(도넛차트), 팔로워 수
4. 카테고리 비율로 종합게임 판정:
   - 2개 이상 게임 카테고리에 15%+ share → 종합게임
   - 단일 게임 80%+ → 해당 게임 전문
   - talk/just chatting 1순위 → 토크 스트리머

Phase 3 — 팔로워 보강 (필요 시):
5. Phase 2에서 누락된 팔로워 → 팔로워 랭킹에서 매칭
   URL: /ranking/followers?platform=naverchzzk
   (101,777채널 풀이므로 대부분 매칭 가능)
```

**장점:** 단일 소스로 전 컬럼 확보, 교차 매칭 불필요  
**제약:** 개별 상세 페이지 방문으로 request 수 증가  
**예상 request budget:**
- Phase 1: 8 requests (랭킹 4p × 2)
- Phase 2: ~100~150 requests (band 범위 채널만 상세)
- Phase 3: ~5~10 requests (누락 팔로워 매칭)
- Total: ~120~170 requests (default budget 200 이내)

**aggregation_window:** 지난 7일 (무료). 개별 페이지 카테고리는 최근 1달.
