### 해석

**발산 확인 — 체급에 따라 방송길이 효과가 다르다:**

- **LC (중소):** 긴 방송 = 더 많은 시청자. r=0.25~0.28, 91%의 채널에서 양의 상관. ~3h(45) → 10-14h(83)로 peak 1.8배. 이는 T1/T2 코호트(309ch, r=0.137~0.208) 결과와 정합. 중소 채널에서 방송시간은 노출-시청자 파이프라인의 유효한 입력.
- **LA (상위):** 방송시간과 시청자 무상관 (r≈0). 채널별로도 44%만 약한 양의 상관. 상위 채널은 이미 노출 포화 상태이므로, 시간을 더 써도 시청자가 늘지 않는다.
- **구비바 (r≈0):** 체급으로 보면 LC급이어야 하는데, 방송길이 효과가 LA급(무상관). 이는 구비바가 이미 월 102.9h(코호트 중앙 5.1h의 20배)를 방송하여 **방송시간의 한계수익이 소진**된 상태임을 시사. 시간을 더 쓸 여지가 없는 것이 아니라, 추가 시간이 시청자로 전환되지 않는 구조.

**§5 정본과의 정합:** §5에서 "구비바는 방송 길이로 avg를 올리기 어렵다"는 판단이 교차검증에서 확인. 다만 원인이 "구비바 고유 특성"이 아니라 "상위 채널에서 나타나는 포화 현상과 동일한 패턴"이라는 추가 해석이 가능.

## 8.3 시간대 효과

### 채널 내 정규화 후 시간대별 peak_z

| 시간대 | LA peak_z | LC peak_z | 구비바 절대값(pk/av) |

### 해석

**발산 확인 — 저녁 시간대 효과는 체급마다 반대 방향:**

- **LC (중소):** 저녁 18-21이 peak_z +0.333으로 **최고 시간대**. 중소 채널에서 저녁은 "주 시청층이 접속하는 프라임타임."
- **LA (상위):** 저녁 18-21이 peak_z -0.125. 상위 채널은 새벽(+0.318)이 최고 → 해외/심야 시청층 구조가 다름.
- **구비바:** 저녁 18-21이 pk 17, av 12로 최저. LC 패턴(저녁=프라임타임)과 정반대.

**§5 정본 미해소 항목 "저녁 성과 저조 원인 미확정"에 대한 추가 단서:** LC 동체급에서 저녁이 프라임타임이라는 것은, 구비바의 저녁 저조가 **시간대 자체의 문제가 아니라 구비바 고유의 요인**(생활국면 정체기 교란, 저녁 게임 타이틀 차이)임을 강화. 시간대 효과와 카테고리 효과의 분리는 여전히 미완이지만, "동체급에서는 저녁이 보통 좋다"는 참조선이 생겼다.

|---|---|---|---|

### 채널 내 정규화 (peak_z)

| 그룹 | game peak_z | talk peak_z | 차이 |
|---|---|---|---|
| LA | +0.006 | -0.016 | game +0.022 |
| LC | +0.032 | -0.184 | game +0.216 |
| 구비바 | — | — | (단일 채널이라 z-score 무의미) |

### 해석

**발산 확인 — 구비바만 talk이 game보다 높다:**

- **LA/LC:** game 방송이 talk보다 peak 높음 (LC에서 +19.6%). 채널 내 정규화 후에도 LC에서 game이 peak_z +0.216으로 유의미한 차이. 게임 콘텐츠가 시청자를 더 많이 끌어오는 것은 중소 채널에서 보편적.
- **구비바:** talk(pk 26) > game(pk 19). §5에서 "오후=AAA싱글, 저녁=온라인/모바일" 혼재를 지적했는데, talk 방송 시 시청자가 더 많다는 것은 **구비바 시청자가 게임이 아닌 스트리머 자체에 반응**하는 구조를 시사.

### 상위 카테고리별 시청자 (채널 내 정규화, LC)

LC에서 peak_z가 높은 카테고리: 음악/노래(+0.233), 니케(+0.135), 명조(+0.131), 이터널리턴(+0.122), 리그오브레전드(+0.114), 검은사막(+0.192).  
peak_z가 낮은 카테고리: 마인크래프트(-0.409), 종합게임(-0.271), 오버워치(-0.211), 미설정(-0.514).

**구비바 카테고리 세부:** peak 중앙값 상위 = talk(19), 젤다(23), 붉은사막(23.5), 명조(23.5), 드래곤볼(25). 하위 = 스텔라블레이드(14), 던파(15.5), 역전재판(15). AAA 싱글 RPG가 상위, 온라인/모바일이 하위. 이는 §5 정본의 "오후=AAA싱글이 좋다" 발견과 정합.

## 8.6 수렴·발산 종합

| 검증 항목 | 판정 | 요약 |
|---|---|---|
| 방송길이→시청자 | **발산(체급 의존)** | 중소(LC)는 긴 방송=더 많은 시청자. 상위(LA)와 구비바는 무상관. 구비바의 무상관은 "방송시간 한계수익 소진"으로 해석 가능. |
| 잔류율×방송길이 | **수렴** | 모든 체급에서 긴 방송=잔류율 하락. 구비바의 감소가 가장 완만. |
| 저녁 시간대 | **발산(구비바 고유)** | 동체급(LC)에서 저녁은 프라임타임(peak_z +0.33). 구비바만 저녁 저조 → 시간대 자체가 아닌 구비바 고유 요인. |
| talk vs game | **발산(구비바 고유)** | LA/LC 모두 game > talk. 구비바만 talk > game → 스트리머 자체 반응 구조. |
| 주중/주말 | **수렴** | 모든 체급에서 주말 소폭 우위. |

### §5 정본 미해소 항목 업데이트

| 미해소 항목 | §8 기여 |
|---|---|
| "저녁 성과 저조 원인 미확정" | 동체급에서 저녁=프라임타임 확인 → 시간대가 아닌 구비바 고유 요인(생활국면/카테고리) 가능성 강화. 완전 분리는 여전히 미완. |
| "카테고리 효과와 시간대 효과 혼재" | LC에서 game > talk 확인. 구비바의 talk > game은 역방향 → 카테고리 효과만으로 저녁 저조를 설명하기 어려움. 복합 요인. |

## 8.7 한계

1. **100행 캡:** SOFTC.ONE DOM 추출이 100행 상한이므로, 장기 활동 채널은 최근 100건만 포함. 초기 방송 패턴과 다를 수 있음.
2. **채널 수 제한:** LA 19ch, LC 23ch. 개별 채널의 특이성이 전체 통계를 흔들 수 있음.
3. **카테고리 분류 정밀도:** 파이프 구분자 기반 1차 분류. 같은 "talk" 안에서도 게임+talk, 순수 talk 등 혼재.
4. **시간대 교란:** 시간대별 n이 불균등 (LA/LC 모두 오전-새벽에 편중). 저녁 n=19~26으로 표본 소.
5. **인과 아닌 상관:** 방송길이↔시청자 상관이 "길게 하면 시청자가 온다"는 아님. 역인과(시청자가 많을 때 길게 함) 가능.
