## 들어가며 — 왜 §1을 넘어섰는가

5차 인터뷰는 *§1 정체성 추출 완료* + *§6·§7·§9 본격 진입*이 동시에 일어난 세션이었음. 이는 *예정된 순서를 벗어난 진행*임. 방법론 v0대로라면 §1 완료 → §2·§3 데이터 분석 → §4 코호트 → §5 진단 → §6 트레이드오프 → §7 콘텐츠 → §8 XGPS → §9 산출물의 순서로 가야 하나, 5차에서 본인 발화가 *§6·§7·§9 영역을 직접 건드림*.

이는 두 가지 이유 때문:

1. **본인 컨설팅 기대 (J1)가 *실행 단계 직결***: "구체 액션 + 정체성 정리 + 고쳐야 할 행동 + 추가할 행동". 본인이 *진단보다 실행*을 원함.
2. **외부 피드백 4년 전무 (C30)**: 본인이 *처음 듣는 외부 의견*에 강하게 반응. 한 영역(§1)에 머무르지 못하고 *연결된 모든 영역*으로 발화 확장.

**함의:** *방법론 v1 보강*의 직접 입력. 정식 의뢰·외부 피드백 부재 클라이언트의 경우 *§1 단계에서 §6·§7·§9 발화가 자연 발생*할 수 있음. 방법론은 *순서 강제*보다 *영역 매핑 + 발화 캡처 + 후속 분석 연결*에 무게.

## §6 목표 트레이드오프 — 진입 자료

> 본인이 명시한 목표(1만 팔로워 + 평균 200명, 1차 인터뷰 23:31)와 본인이 5차에서 자발 공유한 상태(생계 임계점 1/7·전업 같은 취미·영속 의향) 사이의 격차를 다루는 영역.

### 입력 1 — 본인 정량 상태 (C26)

| 항목 | 본인 자발 공유 |
|---|---|
| 생계 임계점 기준 | 최저 월 215만 원 |
| 현재 방송 수입 | 위 기준의 약 1/7 ("용돈 정도") |
| 추정 절대치 | 약 30만 원/월 |
| 본인 톤 | "너무 작고 소듕해" |

**위험 자각:** *본인 즉석 계산* — 정밀도 미검증 (A11). §6 분석 시 본인 재확인 필요.

### 입력 2 — 본인 자기 정의 격차 (C21 일부)

본인 인지 vs 실제 위치:

| 본인 인지 | 실제 위치 |
|---|---|
| "전업 같은 취미 방송" (5/31 21:38) | 전업 본업 (다른 본업 없음, 사이드잡 구직 중) |
| "본업을 잡으려고 하는 중" | 4년차 누적 본업 운영 중 |
| "취미라서 도네 못 받음" (자기 검열) | 운영비·기기·시간 자원 본업급 투입 |

**해석:** 본인 자기 정의가 *현실 위치보다 낮음*. 자기 가치 평가 낮춤(C21)의 일부.

### 입력 3 — 본인 영속 의향 (C23)

- "방송 완전 졸업 생각 없음"
- "본업 잡아도 주 3~4일 줄여서 계속"
- "치지직의 거머리·구머리"
- 3년 후 비전 = 달콤레나·아리사 (팔로워 수치 아닌 *모습*으로 답)

**해석:** 본인은 *단기 급성장 목표*가 아닌 *장기 영속 가능 구조*를 원함. 1만 팔로워 목표의 *의미*가 달라짐.

### 입력 4 — 큰 노선 본인 동의 (C31, D6)

```
방송 안정화 전: 방송을 위한 방송 (대중성 우선)
        ↓
방송 안정화 후: 내가 주도하는 방송 (소울류·토론 등 본인 영역)
```

**해석:** *목표 설정 자체가 2단계*. "1만 도달"이 *안정화 정점*인지 *안정화 통과점*인지 본인이 *직접 합의*. → 1만은 *통과점*에 가까움 (영속 의향 강함).

### §6 분석 시 다뤄야 할 트레이드오프

| 축 | 한쪽 | 다른 쪽 |
|---|---|---|
| 시간 축 | 1만 빠르게 도달 (단기 성장) | 영속적 운영 (장기 지속) |
| 자기 정의 축 | "전업 같은 취미" 유지 (자기 검열 잔존) | 본업 인지 + 도네·콘텐츠 적극화 |
| 콘텐츠 축 | 대중성 우선 (방방봐) | 본인 영역 (소울류·토론) |
| 수입 축 | 임계점 도달 (방송 본업화) | 임계점 미달 + 사이드잡 병행 |
| 자원 분배 축 | 라이브 8h 유지 | 라이브 축소 + 외부 채널 확장 |

**핵심 트레이드오프 — 본인 답이 필요한 것:**

1. *임계점 도달*을 컨설팅 목표로 잡을지, *임계점 미달 상태 지속 가능 구조*를 목표로 잡을지
2. *1만 도달*을 *언제까지*인지 — 데드라인 명시할지 영속 의향에 흡수시킬지

### 위험 자각

- 본인 영속 의향(C23) + 자기 검열(C21)이 *서로 상쇄될* 가능성. 영속 의지는 있는데 *영속 유지에 필요한 도네·콘텐츠 적극화는 자기 검열로 막힘*. §6 분석의 가장 큰 발견 후보.

## §7 콘텐츠 채널 효과 분석 — 진입 자료

> 본방 외 채널(유튜브·SNS 등)이 채널 성장에 실제로 작동하는지 분석. 5차에서 *쇼츠 노선*과 *도네 콘텐츠*가 동시 진입.

### 입력 1 — 외부 채널 현재 상태 (H1)

| 채널 | 상태 |
|---|---|
| 치지직 | 본업 |
| 유튜브 다시보기 | 운영 중 |
| 유튜브 쇼츠 | *완성작 없음* (4년차) |
| 트위터·인스타·블로그·디스코드 | 5차에서 직접 답하지 않음 (다음 인터뷰 영역) |

**진단 (5/31 21:18~22 본인 진술):**
- 유튜브 필요성 인지 ✓
- 기초 편집 가능 (자르기·자막·간단 효과)
- 통일성·편집점에서 막힘
- "이 항아리가 아니야!!!! 하고 깨고 다시 만들고"
- 결과: 완성작 없음

**오너 진단 (5/31 22:54): "어차피 안 할 거"** — 본인 합의.

### 입력 2 — 쇼츠 노선 (5/31 21:24~27)

오너 제안 → 본인 부분 합의:

| 영역 | 본인 답 |
|---|---|
| 게임 외 콘텐츠로 유입 효과 | "맞다고는..? 생각..?" |
| 구소리 토론 → 쇼츠 변환 | 롱폼만 생각해봤음. 쇼츠는 "리뷰 형식 많아서 될까?" 회의적 |
| 게임 영상 포기 어려움 | 명시 |
| 결국 어떤 형식? | "저챗이나 리액션 위주가 맞다고는 생각" |

**5차 결론 — 본인 약속 (5/31 22:58):**
- 다음주까지 쇼츠 영상 1개 (저챗·리액션 위주 추정)
- 본인이 "할 수 있어..!" 자기 합리화 모드로 동의
- O17 트래킹 대상

### 입력 3 — 쇼츠 작동의 두 가능성

**가능성 A — 본인이 만든다:**
- 자가 회복 메커니즘(C22) 작동: 걱정 → 합리화 → 실행
- 본인 "근자감"으로 진입장벽 일시 돌파
- 결과물 품질은 기초 편집 수준

**가능성 B — 본인이 못 만든다 (오너 예측):**
- "이때까지 안 해왔잖아" + "한다고 맨날 말은 많이 했잖아"
- 본인이 *근자감 환청(C22) 후 다시 합리화로 닫음* 가능
- 결과: 4년차 패턴 반복

**§7 분석 시 다뤄야 할 핵심:**
- A·B 어느 결과가 나와도 *본인 행동 패턴 검증 자료*. 본인 외부 채널 확장의 *진입장벽이 어디서 막히는지* 정량 확인.
- A 시: 본인 자가 회복 메커니즘이 *외부 채널 확장에도 작동*함을 확인 → 향후 액션 설계에 활용
- B 시: 본인의 *자기 진단 정확*("근자감 후 다시 막힘" 패턴) 확인 → *외부 의존* 액션 설계 필요 (편집자 구인·MCN 편집 서비스)

### 입력 4 — 편집자 영역 (5/31 22:56)

오너 제시 → 본인 반응:

| 방안 | 본인 반응 |
|---|---|
| 1. 땡구 자원봉사자 모집 | (반응 없음) |
| 2. 쉐어 계약 편집자 구인 | (반응 없음) |
| 3. 소속사 편집 서비스 | (NOB 추천 관련) |
| 4. 본인이 직접 (개과천선) | "나는 나를 너무 믿어서..? 할 수 있다는 근자감..?" |

**진단 (5/31 22:58 오너):** "4는 왜 계속 마음에 걸리시나요" → 본인 "내가 소속사" 자기 정의 진술 (22:00) → *외주화 진입장벽이 자기 정의(C21)에서 옴*. 자기 검열의 한 발현.

### 입력 5 — 도네 마인드 + 시청자 설문 옵션 (C32)

도네 자기 검열 (C21) 영역. 5차에서 *부분 합의*:

| 본인 입장 | 변화 |
|---|---|
| 5/31 21:54~57 | "내가 그 정도의 가치를 할 수 있을까?" — 자기 가치 평가 낮춤. *단단하게 굳어진 생각* |
| 5/31 21:59 | "성장에 도움이 된다면 바뀔 수 있음" + "시청자 의견 우선" 동의 |
| 5/31 22:08 | 직접 토론 거부 — "조언이 빡셌어요" |
| 5/31 22:09~10 | 시청자 설문 옵션 부분 수용 — "외부 채널 자의적 참여 형식이면 OK" |

**§7 분석 시 다뤄야 할:**
- 시청자 설문 형식 권고 (네이버 팬카페·구글 폼 등)
- 본인 가설(추측) vs 실제 시청자 의견 격차 측정
- 결과를 *어떻게 본인에게 전달할지* — 자기 검열이 결과 수용 폭에 영향

**위험 자각 (A9 연계):**
- 본인 자기 검열 메커니즘이 *시청자 설문 결과*가 호의적이어도 *받아들이는 폭은 별개*일 수 있음. 단순 데이터 전달이 아닌 *토론 배틀 형식*(C31) 필요.

### 입력 6 — RP 복원 (C33)

| 영역 | 본인 명시 |
|---|---|
| 복원 여부 | 의지 있음 ("반인반원숭이") |
| 형태 선호 | "완전히 새 컨셉" |
| 기존 외계인 컨셉 | 폐기 ("빡세게 못할 거면 무슨 소용" 사유) |
| 새 컨셉 후보 | "반인반숭이" 자기 어휘 |

**오너 분석 작업 진행 중 (5/31 22:14):** 현재 RP 사용 중인 버튜버 효용가치 분석. → §9 산출물에 RP 복원 옵션 포함 결정 (O8).

### 입력 7 — 콘텐츠 확장 재료 (C34)

본인 자발 노출 (5/31 22:15~16):
- 영화 — 공포 장르 ("지금 가장 큰 취미")
- 미국 애니
- 음악 (말 시작했다가 멈춤)

**§7 분석 시 다뤄야 할:**
- 영화(공포) → 콘텐츠 결합 가능성 (공포 게임은 이미 함 / 공포 영화 리뷰·시청 콘텐츠 가능성)
- 미국 애니 → 본인 정체성과의 결 (취향이 *대중적 일본 애니 아닌* 위치 — 차별화 단서)
- 음악 → 노래 콘텐츠 진입 가능성 (단 본인 "노래 못 함" 자기 인지 — MCN 미고려 사유 중 하나)

## §9 산출물 / 외부 연결 — 진입 자료

> 컨설팅 산출물 형식 + 외부 연결(MCN 추천) 영역. 5차에서 NOB 엔터테인먼트 추천 결정 + 통합 진단 전달 형식 설계 필요성 박힘.

### 입력 1 — 본인 컨설팅 기대 (J1, C14)

5/31 19:08 본인 답:
- (나) 6개월·1년 안에 시도할 *구체 액션* >> 이거!
- (다) 콘텐츠 방향·정체성 *확정·정리* >> 이거!
- (마) "어떤 행동을 *고쳐야 하고* 어떤 행동을 *추가하면 좋을지* 알고 싶습니다!!!"

**해석:** 본인 기대 = *실행 단계 (what to do + how to)*. 진단 리포트(김달수 케이스 표준)와 *다른 형식* 필요.

### 입력 2 — 산출물 응대 우선순위 (D8)

매력 의심 해소 1순위 (D6·C25). 산출물에서 *매력 의심을 어떻게 해소할지*가 1번 가치.

**김달수 케이스 학습:** 1년 +227% 발견이 본인에게 가장 큰 임팩트였음. 구비바 케이스도 *발전 정량화*가 자기 의심 해소 도구로 작동 가능. 시기별 4구간(C8) 자기 발전 인지를 *외부 지표 측정값과 정렬*하여 본인 인지 격차 해소.

### 입력 3 — 통합 진단 전달 형식 (O13, A9)

§1 v3의 가장 큰 발견 = **자기 가치 평가 낮춤 통합 진단** (C21):
- 매력 의심 (D6)
- 도네 자기 검열 (5/31 21:57)
- "전업 같은 취미" 자기 정의 격차 (5/31 21:38)

→ 이 셋이 *동일 뿌리*. 본인 명시 확인 안 됨 → 산출물 전달 시 본인 반응으로 검증.

**전달 형식 설계 (별도 작업, O13 우선):**
- 단순 진단 전달이 아닌 *토론 배틀 형식*(C31)으로 가야 본인 의사결정 메커니즘과 정합
- v2 A2 가설 철회(K1) 교훈: 본인 인지와 어긋날 가능성 주시
- *납득 가능한 근거*(데이터·시청자 의견·외부 시선) 동반 필수

### 입력 4 — MCN(NOB 엔터테인먼트) 추천 (C27, O15)

**진행 상태:**
- 본인 동의 받음 (5/31 22:25~26)
- 환생 없는 조건이면 긍정
- 오너 액션: NOB 대표님 미팅 시 김달수 케이스 연결과 함께 구비바 언급
- 사전 작업: 오너가 먼저 NOB 염탐 후 본인에게 보고

**MCN 의미 — 본인 영역에서:**
- 4년 외부 피드백 전무(C30) 환경 해소
- 편집자 영역 진입장벽(C21·자기 검열) 해소 — 소속사 편집 서비스
- 자기 의심(C25 매력) 해소의 *외부 검증* 작동
- 단 *회사 시스템 미적응*은 본인 자기 진단 (5/31 23:01~02)

**위험:**
- 본인 *납득 메커니즘*(C31)이 MCN 가입 결정에 작동해야 함
- MCN 측 제안이 본인 *콘텐츠 영역*(소울류·미스터리 등)과 어긋나면 본인 *납득 안 되면 닫힘* 패턴(C31)

### 입력 5 — 자가 회복 메커니즘 인지된 전달 (C22)

본인 자가 회복 패턴:
```
걱정 한계선 도달 → 일기·관련 유튜브 → 자기 합리화 → 긍정 전환
```

**§9 산출물 전달 시 활용:**
- 산출물 전달 직후 본인이 *걱정 폭주* 가능성 — 본인이 진술한 *기존 패턴* (5/31 22:49 토론 배틀 시뮬레이션에서 본인 "엌 나잖아..?" 동의)
- 전달 후 *본인 자가 회복 시간 확보* 권고 (즉답 강제 X)
- 후속 응대(다음 인터뷰)에서 본인 *합리화 후 결론*을 받음

### 입력 6 — 산출물 두 형식 결정 (김달수 표준 적용)

김달수 케이스 학습: 친근형 HTML + 정식 MD 두 형식.

구비바 케이스 적용:
- **친근형:** 본인 어휘 톤 차용 가능 ("구사장님~"). 본인 자가 회복 메커니즘 작동 도구. 1순위.
- **정식 MD:** 외부 공유·기록용. 익명화 시 *기능어 치환*(C35).

**추가 형식 후보 (구비바 케이스 신규):**
- *토론 배틀 형식 보조 자료* — 본인 의사결정 메커니즘(C31)에 맞춤. 산출물 후 *후속 토론*에서 활용.

## 영역 간 연결 — 통합 진단(C21)이 §6·§7·§9 모두에 작동하는 방식

```
자기 가치 평가 낮춤 (C21)
  ├─ §6 영역: "전업 같은 취미" 자기 정의 → 목표 설정 격차
  │           1만 팔로워가 도달점인지 통과점인지 본인이 못 정함
  │
  ├─ §7 영역: 도네 자기 검열 → 콘텐츠 확장 막힘
  │           시청자 의견 우선 동의했으나 *수용 폭 별개*
  │           편집자 외주화도 "내가 소속사" 자기 정의로 막힘
  │
  └─ §9 영역: 매력 의심 → 산출물 응대 1순위
              산출물에서 자기 의심 해소가 핵심 가치
              MCN 추천도 외부 검증으로 작동
```

**해석:** §6·§7·§9 어디서 작업하든 *C21 통합 진단*이 *공통 뿌리*로 작동. O13(통합 진단 전달 형식) 설계가 *전체 산출물의 핵심 모듈*이 될 가능성.
