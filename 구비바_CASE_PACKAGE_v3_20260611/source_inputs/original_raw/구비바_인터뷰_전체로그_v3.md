- 컨설팅 액션과의 의사결정: *납득이 되면 받아들임* + *토론 배틀로 합의*
- 다음주까지 쇼츠 영상 1개 숙제

## 5차 종료 시점 누적 상태

### 1·2·3·4차 + 5차 통합 §1 상태

- **본인 의도 어휘:** 광대+샌드백 / 동네 누나·여동생 / 종합게임 힐링
- **본인 명명 4어휘:** 광대 스타일·구소리·방방봐·구징징
- **시청자 수용:** 멘헤라 꾸숭이·구사장·구바보·꾸삐삐·꾸숭이·꾸삐삐 수호단
- **분리 보호:** 진심펀치(분노) + 신원 정보
- **부분 콘텐츠화:** 깊이 축(토론·소울류·미스터리)
- **자기 의심 우선:** 매력 > 실력 > 설정
- **자기 검열:** 도네 거부 ("너 뭐 됨?") + "전업 같은 취미" 자기 정의
- **자가 회복:** 걱정 한계선 → 일기·유튜브 → 합리화 → 긍정 전환
- **영속 의향:** "치지직 거머리·구머리"
- **3년 비전:** 달콤레나·아리사

### 신규 §6·§7·§9 진입

- §6: 1만 팔로워 vs 영속성 트레이드오프
- §7: 유튜브 쇼츠 노선 + 도네 콘텐츠 시청자 설문 옵션
- §9: MCN(NOB) 추천 진행 + RP 복원 새 컨셉(반인반원숭이)

### 5차 본인 자발 정량 공유

- 생계 임계점 (월 215만) 대비 현재 ≈ 1/7 ("용돈 정도")

- 단골 약 10명 + 극초기 잔류 약 5명
- 콘텐츠 확장 재료: 영화(공포)·미국 애니·음악
