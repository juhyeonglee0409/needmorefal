## 컨셉 요약

**"언니채널"** = 자신과 유사한 환경(장르, 방송패턴, 체급)이지만 성과가 한 단계 위인 채널.
환경변수를 자연 통제한 상태에서 "다른 점"을 찾아 이식 가능한 레버를 식별하는 방식.

통계적으로는 **Matched-Pair Design** 또는 **Synthetic Control**에 해당.
단일 채널 회귀 분석(교란변수 스캔)의 한계 — 측정 안 된 변수를 통제할 수 없음 — 를 보완함.

### 비교 분석 시 확인할 "다른 점"

언니채널이 정해지면, 아래 차원에서 차이를 비교:

- **방송 시작 시각** (구비바 OLS에서 비유의였지만, 채널 간 비교에서는 유의할 수 있음)
- **방송 제목/썸네일 패턴** (데이터 수집 가능 — 방송별 요약에 시작제목 있음)
- **채팅 밀도** (전체 채팅수 / 방송시간)
- **팔로워 대비 시청자 비율** (커뮤니티 충성도 프록시)
- **카테고리 전환 전략** (어떤 게임에서 어떤 게임으로, 시청자 이탈 패턴)
- **유튜브/외부 채널 운영** (§7에서 확인한 유튜브 효과와 연계)

## C. 방법론 한계 & 다음 단계

### 한계

1. **관측 불가 변수**: "화법", "게임 실력", "편집 감각", "커뮤니티 문화" 등은 데이터로 매칭 불가. 최종적으로 직접 시청·비교가 필요.
2. **코호트 범위**: 구비바 코호트는 chzzk 종합게임 VTuber 위주, 김달수 코호트는 peak 74~296 LoL 채널 위주. 코호트 밖의 잠재 언니채널은 포착 안 됨.
3. **시점 차이**: 코호트 데이터는 수집 시점 기준. 현재 활동 상태는 재확인 필요.
4. **버추얼 확인**: 구비바 메인 코호트의 버추얼 상태가 대부분 미수집. aux_virtual 교차 확인으로 6/10 확인.

### 다음 단계 (제안)

1. **후보 2~3개 선정**: 에셔·구비바가 위 리스트에서 "방송을 직접 봤을 때 따라할 수 있겠다" 싶은 채널 선택.
2. **방송 데이터 상세 비교**: 선정된 언니채널의 방송별 요약을 구비바/김달수와 나란히 놓고 정량 차이 분석.
3. **관측 불가 차원 직접 비교**: 1~2회 방송을 직접 시청하면서 "무엇이 다른지" 정성적 메모.
4. **차이 → 액션**: 발견된 차이 중 이식 가능한 것을 Phase 1 액션에 추가.
