## Step 0: tls-client WAF 우회 테스트 (최우선)

본 수집 시작 전에 tls-client가 SOFTC.ONE Vercel WAF를 통과하는지 반드시 테스트한다.

### 테스트 스크립트

```python
# pip install tls_client
import tls_client, time

session = tls_client.Session(
    client_identifier="chrome_120",
    random_tls_extension_order=True
)

# Test 1: ranking page
url1 = "https://viewership.softc.one/ranking/virtualsoftcone?type=naverchzzk"
r1 = session.get(url1)
waf1 = "Vercel Security" in r1.text[:1000]
rsc1 = "__next_f" in r1.text
print(f"[ranking] status={r1.status_code}, WAF={waf1}, RSC={rsc1}, len={len(r1.text)}")

time.sleep(2)

# Test 2: channel card (구비바)
url2 = "https://viewership.softc.one/channel/269edc95873a1ec9fc534851c0783d1f,naverchzzk"
r2 = session.get(url2)
waf2 = "Vercel Security" in r2.text[:1000]
rsc2 = "__next_f" in r2.text
print(f"[channel] status={r2.status_code}, WAF={waf2}, RSC={rsc2}, len={len(r2.text)}")

time.sleep(2)

# Test 3: broadcast history API (RSC flight 추정)
# SOFTC.ONE은 Next.js App Router — 방송기록 탭은 클라이언트 라우팅.
# RSC flight URL 패턴 시도:
url3 = "https://viewership.softc.one/channel/269edc95873a1ec9fc534851c0783d1f,naverchzzk/broadcast"
r3 = session.get(url3)
waf3 = "Vercel Security" in r3.text[:1000]
print(f"[broadcast] status={r3.status_code}, WAF={waf3}, len={len(r3.text)}")
```

### 판정 기준

| 결과 | 판정 | 다음 단계 |
|---|---|---|
| WAF=False, RSC=True | **통과** — tls-client로 전량 수집 가능 | RSC payload에서 방송기록 데이터 추출 로직 작성 → 70채널 자동 수집 |
| WAF=True 또는 429 | **차단** — tls-client 불가 | playwright (CLI) 수집으로 전환. Arthur CLI `--best-path playwright` 사용 가능 |
| RSC=True but 방송기록 데이터 없음 | **부분 통과** — 채널 카드는 뚫리나 방송기록은 별도 API | 브라우저 네트워크 탭에서 방송기록 API endpoint 확인 필요 |

tls-client 통과 시 70채널 × 1요청 = ~3분이면 끝난다. 차단 시 playwright로 전환하되 채널당 5~10초 × 70 = ~10분.

### 추가 client_identifier 시도 (chrome_120 차단 시)

```python
for cid in ["chrome_120", "chrome_124", "firefox_120", "safari_16_0"]:
    s = tls_client.Session(client_identifier=cid, random_tls_extension_order=True)
    r = s.get(url1)
    print(f"{cid}: status={r.status_code}, WAF={'Vercel Security' in r.text[:1000]}")
    time.sleep(2)
```

## 속도 제한

- SOFTC.ONE은 Vercel WAF 사용. 채널 간 2~3초 간격 유지.
- 429 받으면 30초 대기 후 재시도. 연속 429 3회시 중단하고 보고.
- httpx/curl은 429 차단됨. tls-client 또는 playwright 또는 실제 브라우저 필요.
