## 9.1 전달 구조 설계

### 9.1.1 받는 사람

구비바 본인 1명. 의뢰자·소속사·매니저 없음. **→ 친근형 + 토론 배틀 보조** (방법론 §9.2 선택 기준).

### 9.1.2 전달 채널

디스코드 화면공유 (1부와 동일). 문서를 화면에, 보고가이드를 별도 창에.

### 9.1.3 전달 단위

1부(진단편)는 이미 보고가이드 v1로 전달 시나리오 완성. **2부(분석편+전략편)가 미설계.**

2부는 1부와 톤이 다르다. 1부는 "지금 어디에 있는지"(위치 확인), 2부는 "왜 그런지 + 어떻게 바꿀지"(원인 진단 + 전략). 2부에서 O13 통합진단이 들어간다.

## 9.3 O13 통합진단 — 토론 배틀 보조

### 9.3.1 통합진단 구조

```
[뿌리 가설]
"매력 의심, 도네 자기검열, '전업 같은 취미' 자기정의 — 
이 세 가지가 별개가 아니라 같은 뿌리에서 나온다."

뿌리 = 자기 가치 평가 낮춤
```

### 9.3.2 세 가지 현상 → 하나의 뿌리

| 현상 | 본인 발화 (출처) | 뿌리 연결 |
|---|---|---|
| 매력 의심 | "매력, 실력 둘 다 비슷하게 부족하다고는 생각하는데 매력이 쪼금 더 위인듯" (D6, 5/31 21:29) | 자기 가치 → "나는 매력이 부족하다" |
| 도네 자기검열 | 시청자 정서 과민감 → 후원 요청 자체를 억제 | 자기 가치 → "내가 후원받을 만큼은 아니다" |
| 자기정의 격차 | "전업 같은 취미" — 방송량 월 102.9h(코호트 20배)인데 "취미" | 자기 가치 → "나는 전업이라 부를 수준은 아니다" |

### 9.3.3 데이터 근거 (토론 시 활용)

| 근거 | 수치 | 해석 |
|---|---|---|
| 잔류율 상위 14% | 0.712, 576ch 중 86.4%ile | "매력 부족이면 시청자가 안 남아요. 상위 14%는 매력 증거" |
| 채팅 참여 1.6~1.9배 | 코호트 대비 | "시청자가 적극적으로 반응. 매력 부족 채널에선 안 나오는 패턴" |
| talk > game 역전 | §8 XGPS, LA/LC 모두 game 우세인데 구비바만 역전 | "게임이 아니라 당신을 보러 온다는 증거" |
| 방송시간 102.9h/월 | 코호트 중앙 5.1h의 20배 | "'취미'라는 자기정의와 실제 투입량의 괴리" |
| §1 3층 일치 | 본인인식=콘텐츠실제=시청자수용 | "정체성 일치가 코호트에서 드문데, 구비바는 거의 완벽 일치" |

### 9.3.4 토론 배틀 스크립트

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[발견] 세 가지가 같은 뿌리에서 나온다

우리 분석:
  매력 의심, 도네 자기검열, "전업 같은 취미" 자기정의.
  이 세 가지가 별개 문제가 아니라
  "나는 그 정도는 아니다"라는 동일한 자기 평가에서 나온다.

근거:
  1. 잔류율 상위 14%, 채팅 참여 1.6~1.9배
     → 객관적 매력 지표는 상위권
  2. 시청자가 게임이 아니라 구비바를 보러 옴 (talk > game)
     → 스트리머 자체의 매력이 작동하고 있음
  3. 월 102.9h 방송 (코호트의 20배)
     → "취미"라고 부르기엔 투입량이 전업 수준

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[예상 반응 1] "그래도 진짜 매력 있는 사람은 더 잘하잖아요"

  → "더 잘하는 사람은 있어요. 하지만 '매력이 없다'와 
     '더 매력적인 사람이 있다'는 완전히 다른 얘기예요.
     상위 14%는 매력이 없는 수치가 아니에요."

  → 자기 검열 발현 체크:
     "더 잘하는 사람과 비교해서 자기를 깎는 패턴,
      이게 정확히 우리가 말하는 '자기 가치 평가 낮춤'이에요."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[예상 반응 2] "도네는 진짜 부담스러운 건데요"

  → "부담스러운 건 맞아요. 그 감정 자체는 자연스러워요.
     질문은 '부담스러움의 크기'가 적정한가예요.
     코호트에서 비슷한 규모 채널들은 도네를 받고 있어요.
     부담이 '안 받는 게 정상'이 아니라 
     '자기 가치를 낮게 봐서 과도하게 억제하는 것'일 수 있다는 거예요."

  → 본인 판단 존중:
     "최종 판단은 본인이 해요. 
      우리는 '그 억제가 어디서 오는지'를 보여드리는 거예요."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[예상 반응 3] "전업 같은 취미가 뭐가 문제예요?"

  → "문제라는 게 아니에요. 
     자기정의와 실제 투입량의 괴리를 보여드리는 거예요.
     월 103시간은 코호트 평균의 20배예요.
     이 투입량으로 '취미'라고 부르는 건,
     자기가 하는 일의 가치를 낮게 보는 것과 같은 구조예요."

  → 전환:
     "이게 '고쳐야 한다'가 아니라 '인식하면 좋겠다'예요.
      인식하면 도네 태도나 성장 전략에서 선택지가 늘어나요."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[예상 반응 4] 침묵 또는 과부하

  → "무거운 얘기인 거 알아요. 지금 당장 답 안 해도 돼요.
     며칠 생각해보고 나중에 말씀해주셔도 되고요."

  → 즉답 강제 금지. 자가 회복 시간 확보.
     다음 연락 시 반응 확인.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[분기 판단]

  본인이 수용 → §10 실행 매뉴얼에 "자기 가치 인식" 반영
  본인이 부분 수용 → 수용 부분만 액션화, 거부 부분 open 유지
  본인이 거부 → 결론 수정 또는 근거 재검토. C21을 killed로 전환
  본인이 과부하 → 시간 두고 재시도
```

### 9.3.5 전달 위험 관리

| 위험 | 대응 |
|---|---|
| "매력 없다"를 정면 부정하면 본인이 방어적 | 근거부터 제시, 판단은 본인에게 |
